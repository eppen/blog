EOS 菜单树 NodeID 与 ObjectID 说明

本文档说明 eosrole 页面「配置 EOS 菜单权限」树节点中 NodeID（前端 zTree 的 id）与 ObjectID（前端 objectId）的含义、数据库来源、后端组装与前端使用方式。

关联文档：EOS 菜单与角色关联关系说明

2026-07-31 更新：权限树接口额外返回 menuType / sysMenuId；保存 body 含 MES 按钮与 ERP 操作扩展字段。

结论摘要

前端字段 含义 数据库来源 主要用途
zTree id 菜单节点 ID messys.Tree.NodeID 树结构、父子关系（pId）；前端勾选态缓存键
zTree objectId EOS 权限对象 ID messys.Tree.ObjectID = messys.ObjectRegister.ObjectID 角色菜单授权（STPermission.ObjectID，「执行」）
zTree menuType 菜单类型 EosMenuTypeHelper.resolveMenuType mes / erp / folder，决定右侧详情面板
zTree sysMenuId MES 菜单 ID 优先 sys_menu_eos_node，否则 NodeDesc=MES_MENU: MES 菜单/按钮写入 sys_role_menu

NodeID 与 ObjectID 是两套独立编号体系，不可混用。角色菜单「执行」授权必须使用 ObjectID；NodeID 用于树层级与 detail 查询参数。

1. NodeID 是什么

NodeID 是 EOS 菜单树 messys.dbo.Tree 的主键，标识一个菜单/目录节点在树中的位置。

在 MES 前端 zTree 中，NodeID 映射为节点的 **id**（idKey: "id"），ParentID 映射为 **pId**，用于渲染树形结构与展开/折叠。前端勾选态 permissionCheckedNodeIds 也按 NodeID 缓存。

NodeID 不写入 STPermission。权限表引用的是 ObjectID。detail 接口用 nodeId 定位节点后再解析业务 ObjectID。

2. NodeID 从哪来

2.1 数据库表

表 库 字段 说明
Tree messys NodeID 菜单节点主键
Tree messys ParentID 父节点 NodeID（根为 0）
UniqueNO messys No 下一个可用 NodeID（NName='tree'）

2.2 MES 新建节点时的分配逻辑

MES 通过 TreeServiceImpl.getNextNodeIdForTree() 从 UniqueNO 表取号：

  1. 悲观锁查询 UniqueNO 中 NName='tree' 的记录（PESSIMISTIC_WRITE）
  2. 取当前 No 作为新 NodeID
  3. 将 No + 1 写回，占用该编号

2.3 触发 NodeID 分配的操作

操作 方法 说明

3. ObjectID 是什么

ObjectID 是 EOS 对象注册表 messys.dbo.ObjectRegister 的主键。每个可授权对象在 ObjectRegister 中注册一条记录；菜单/目录节点对应 TypeID = 7，并通过 OwnerID = Tree.NodeID 与菜单树关联。

MES 维护菜单时会将 ObjectID 冗余写入 Tree.ObjectID，便于权限树接口一次查询带出。

在角色菜单授权场景下，前端勾选菜单后提交的是 objectId 列表，写入 mesdata.dbo.STPermission.ObjectID（配合 UserID=角色 OID、Oprate=「执行」、Permission=1）。

6. 运维与开发建议

  1. EOS 客户端菜单权限：可在 EOS 原生安全管理中配置，也可在 MES eosrole「配置菜单权限」中配置；数据均写入 mesdata.dbo.STPermission。运维排查可用上文 SQL。
  2. MES 页面权限：可在「系统管理 → 角色管理」勾选 sys_menu；也可在 eosrole 中为 MES Web 菜单勾选按钮（写入同一 sys_role_menu）。菜单「执行」可见性仍依赖 STPermission。
  3. 两套菜单数据源：
    • Tree / ObjectRegister：EOS 客户端 / Web 壳菜单
    • sys_menu：MES 页面与 Shiro 权限
    • eosrole 可在同一弹窗统一配置两侧，但没有从 STPermission 自动全量同步到 sys_role_menu（或反向）的后台任务；MES 按钮仅在 eosrole 保存时写入。
  4. 从 EOS 同步角色后：若需在 MES Web 中使用该角色的菜单/按钮，可在角色管理中分配，或在 eosrole 配置菜单权限时一并提交 mesMenuIds / mesButtonMenuIds。
  5. 跨库注意：STUsers、STPermission、STUserGroup、sys_* 在 mesdata；Tree、ObjectRegister 在 messys，关联字段为 STPermission.ObjectID ↔ ObjectRegister.ObjectID。

瘦身密码（五）：甜蜜陷阱——肥胖引爆的八大健康地雷

肥胖是健康的「隐形杀手」——影响的不只是外形，而是心血管、代谢、内分泌、呼吸、骨骼、生殖乃至心理的全系统连锁反应。以下梳理书中重点阐述的八大健康地雷及应对思路。

1. 糖尿病：胰岛素遇上甜甜圈

中国 20～79 岁人群糖尿病患病率约 10.6%，患病人数约 1.41 亿。肥胖与糖尿病如影随形：

  • 体重每增加 1 kg，糖尿病风险至少升 5%
  • 约 50% 肥胖者将来可能患 2 型糖尿病
  • 糖尿病患者中约 2/3 超重或肥胖

机制：内脏脂肪像「棉袄」包裹细胞，胰岛素（钥匙）难以与受体（锁）结合，葡萄糖进不了细胞 → 胰岛素抵抗 → 代偿性高胰岛素 → 食欲增加 → 更胖 → 最终血糖失控。

逆转密码：

  • 少吃深加工食品、奶茶炸鸡；多吃蔬菜、粗粮
  • 中低强度有氧运动，餐后 30～60 分钟，每次 ≥30 分钟，约 200～300 千卡
  • 超重人群 35～70 岁应每 3 年筛查血糖
  • 九体医学统计：气虚质、阴虚质、痰湿质最易患糖尿病

2. 冠心病：糖脂风暴下的冠状动脉

冠心病患者超重/肥胖率超 50%。BMI 越高，冠心病发病率越高；肥胖者患病概率约为常人 2～3 倍，超平均体重 40% 者死亡风险翻倍。

机制：肥胖 → 血脂紊乱 → 动脉粥样硬化斑块 → 冠脉狭窄 → 心肌缺血。心脏如同小发动机驱动重型卡车，长期超负荷终将「罢工」。

逆转密码：减重 + 控脂 + 戒烟限酒 + 规律运动；编写细胞层面的「燃脂程序」，减轻心脏负担。

3. 睡眠呼吸暂停：内脏脂肪的午夜叛乱

腹型肥胖者脂肪堆积在呼吸道周围，气道变窄，睡眠时呼吸暂停 → 缺氧 → 睡眠质量差 → 日间嗜睡 → 活动减少 → 更胖，形成死亡循环。

逆转密码：减重是核心；侧睡、避免睡前饮酒；严重者需呼吸机等医学干预。

4. 脂肪肝：内脏的「垃圾处理厂」瘫痪

超重/肥胖者并发症中，脂肪肝最常见之一。肝脏本应将脂肪打包运出，糖尿病与肥胖使这一过程效率降低，脂肪在肝内堆积。

常见认知陷阱（书中强调）：

  • 「不胖就不会脂肪肝」——瘦人脂肪肝也不少见
  • 「无症状就不用管」——可进展为肝纤维化
  • 「只吃素就能好」——关键在于总能量与代谢
  • 「护肝片够用了」——病因不除，难以逆转

逆转密码：减重 5%～10% 常可显著改善肝脂肪变；控糖控脂 + 运动。

5. 骨关节炎：关节的载荷安全阈值

体重每增加 1 kg，膝关节承受压力约增加 3～4 kg。肥胖 → 慢性炎症 → 软骨磨损加速。

逆转密码：减重减轻关节负荷；水中运动、肌力训练增强关节稳定性。

6. 多囊卵巢综合征：激素风暴

肥胖与多囊卵巢相互加剧：脂肪组织干扰激素平衡，胰岛素抵抗推高雄激素，影响排卵与生育。

逆转密码：减重 5%～10% 可显著改善月经与排卵；生活方式干预是一线治疗。

7. 乳腺癌：癌变风险的土壤

肥胖改变雌激素等激素水平，脂肪组织释放炎症因子，为癌细胞生长提供「土壤」。腹型肥胖与多种妇科、消化道肿瘤风险相关。

逆转密码：保持健康体重、规律筛查、减少久坐。

8. 心理沼泽：身材焦虑与情绪雪崩

肥胖与心理相互纠缠：

  • 自尊心、自我形象受损
  • 焦虑 → 暴食 → 更胖 → 更焦虑
  • 脂肪组织炎症因子可能影响大脑情绪通路
  • 社会偏见与「体型歧视」加重心理负担
  • 极端节食或暴食交替，饮食成为情绪的「翻译器」

逆转密码：接纳与改变并行；寻求心理咨询；用运动、社交替代情绪性进食；体重管理应是关爱自己，而非自我惩罚。

九体视角下的并发症预防

不同体质易患不同慢病，调理应有的放矢：

体质 相关风险
痰湿质 肥胖、高血压、糖尿病、高血脂
气虚质 感冒、内脏下垂、乏力
阳虚质 畏寒、腹泻、痹证
阴虚质 失眠、咽痛、「三高」
血瘀质 肿瘤、痛证、卒中
气郁质 甲状腺、乳腺疾病、情绪障碍

体质可调——在并发症尚未形成前调体，是最好的「逆转密码」。

系列结语

《瘦身密码》传递的核心信息可以概括为三句话：

  1. 中国肥胖形势严峻，腰围与 BMI 同样值得每日关注
  2. 科学减肥是马拉松，忌节食、代餐、极端断食
  3. 九体医学提供个体化路径——先识体质，再管体重，方能健康瘦身不反弹

2024 年国家「体重管理年」已经启程。愿我们都不再以「换大码裤子」为常态，而是在读懂自己身体密码的基础上，走出属于自己的健康之路。

瘦身密码（四）：九大体质科学甩肉指南——管体加管重

核心理念：管体 + 管重

  • 管体：辨识体质、纠正偏颇——体质调好了，赘肉才不容易反弹
  • 管重：吃对食物比盲目少吃更重要；体重是体质的一面镜子，但不是唯一指标

同样体重的人，体脂率、肌肉量不同，健康状况可以天差地别。短期节食难持久，结合体质的长期调理才是正道。

平和质：别把好体质作没了

特征：体形匀称，精力充沛，患病少，适应力强。

要点：

  • 膳食平衡，粗粮细粮搭配，寒温适中，七八分饱
  • 每天有氧运动约 30 分钟，或步行不少于 6000 步
  • 22:30 前入睡，春夏养阳、秋冬避风寒
  • 穴位保健：足三里、三阴交、涌泉

药膳举例：南瓜豆腐羹、芝麻山药粥

阳虚质：扶阳驱寒是关键

特征：怕冷、手足凉、夜尿多、精神不振，脂肪像给身体「穿羽绒服」。

要点：

  • 避寒就温，多晒太阳，睡前 40～45℃ 泡脚 15 分钟
  • 宜羊肉、鸡肉、韭菜、核桃；少生冷、少苦寒苦瓜（可煮透减寒）
  • 运动选慢跑、太极拳、八段锦，微汗为度，忌大汗伤阳
  • 穴位：关元、命门、阳池

药膳举例：暖胃茶（红茶+桂圆+生姜+白术+红枣）、当归生姜羊肉汤

阴虚质：补水降火是核心

特征：口干咽燥、手足心热、盗汗、便干，体型偏瘦但血脂易偏高。

要点：

  • 忌熬夜、桑拿、高温环境；室温 14～26℃ 为宜
  • 宜芝麻、蜂蜜、豆腐、鱼类；少辛辣燥烈、火锅
  • 运动选游泳、瑜伽、散步，避免大汗淋漓
  • 穴位：太溪、三阴交、大敦

药膳举例：三汁饮（黄精、生地、天门冬、茯苓）、冰糖五果羹

气郁质：疏肝解郁才能瘦

特征：多愁善感、胸闷叹息、睡眠差；一焦虑就暴食，压力肥堆腰腹。

要点：

  • 环境宜安静，春季多户外活动舒展阳气
  • 宜萝卜、洋葱、柑橘；玫瑰花、茉莉花代茶饮
  • 少芋艿、甘薯等易胀气食物
  • 推荐：玫瑰花茶 + 敲胆经，疏解肝郁

药膳举例：萝卜丝饼、玫瑰佛手茶

血瘀质：活血化瘀加速瘦身

特征：面色晦暗、唇舌黯、黑眼圈，肉硬腿粗，减肥进展慢如「挤牙膏」。

要点：

  • 少食肥腻、寒凉，宜活血食物：山楂、黑豆、玫瑰花
  • 运动促进血液循环，避免久坐
  • 药浴泡脚 + 山楂茶是经典组合
  • 穴位：血海、膈俞、三阴交

痰湿质：祛湿排浊才是真抽脂

特征：体胖腹大、身重困倦、痰多、鼾声大，减肥易卡平台期。

要点：

  • 饮食清淡：冬瓜、白萝卜、薏米、赤小豆；少甜腻、少暴饮暴食
  • 忌潮湿环境，宜阳光下午后运动
  • 按揉丰隆、足三里、中脘；红豆薏米汤、山药冬瓜汤
  • 古籍云：「肥人多痰湿」——祛湿比单纯节食更关键

湿热质：清火除湿瘦成清爽

特征：面油痤疮、口臭、便黏，脸油肚凸的「油胖子」。

要点：

  • 宜冬瓜、绿豆、苦瓜、芹菜；忌辛辣、油炸、甜腻
  • 运动选中长跑、游泳等耗湿清热项目
  • 冬瓜汤、刮肝经，拒绝油腻感
  • 穴位：阴陵泉、曲池、委中

气虚质：补气提效懒人瘦身

特征：疲乏气短、声低懒言、易感冒，肉松垮像棉花。

要点：

  • 宜山药、大枣、鸡肉、黄芪；忌过劳、过饱
  • 运动从散步、八段锦入手，循序渐进，忌大汗
  • 黄芪水 + 八段锦，提升运化效率再减重
  • 穴位：气海、脾俞、足三里

特禀质：温和调理避开雷区

特征：易过敏，减肥过激易诱发风团、喷嚏。

要点：

  • 低敏饮食，避开已知过敏原
  • 运动环境清洁，避免花粉、尘螨密集处
  • 穴位按摩宜轻柔；中药调理需严格遵医嘱
  • 减肥方案宜缓不宜猛

写在最后

九体医学告诉我们：没有放之四海而皆准的减肥法。痰湿要祛湿，阳虚要温阳，气郁要疏肝，气虚要补气——先调体，再管重，才能瘦得健康、瘦得长久。
