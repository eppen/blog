EOS 菜单树 NodeID 与 ObjectID 说明

本文档说明 eosrole 页面「配置 EOS 菜单权限」树节点中 NodeID（前端 zTree 的 id）与 ObjectID（前端 objectId）的含义、数据库来源、后端组装与前端使用方式。

关联文档：EOS 菜单与角色关联关系说明

2026-07-31 更新：权限树接口额外返回 menuType / sysMenuId；保存 body 含 MES 按钮与 ERP 操作扩展字段。

结论摘要

前端字段 含义 数据库来源 主要用途
zTree id 菜单节点 ID messys.Tree.NodeID 树结构、父子关系（pId）；前端勾选态缓存键
zTree objectId EOS 权限对象 ID messys.Tree.ObjectID = messys.ObjectRegister.ObjectID 角色菜单授权（STPermission.ObjectID，「执行」）
zTree menuType 菜单类型 EosMenuTypeHelper.resolveMenuType mes / erp / folder，决定右侧详情面板
zTree sysMenuId MES 菜单 ID 优先 sys_menu_eos_node，否则 NodeDesc=MES_MENU: MES 菜单/按钮写入 sys_role_menu

NodeID 与 ObjectID 是两套独立编号体系，不可混用。角色菜单「执行」授权必须使用 ObjectID；NodeID 用于树层级与 detail 查询参数。

1. NodeID 是什么

NodeID 是 EOS 菜单树 messys.dbo.Tree 的主键，标识一个菜单/目录节点在树中的位置。

在 MES 前端 zTree 中，NodeID 映射为节点的 **id**（idKey: "id"），ParentID 映射为 **pId**，用于渲染树形结构与展开/折叠。前端勾选态 permissionCheckedNodeIds 也按 NodeID 缓存。

NodeID 不写入 STPermission。权限表引用的是 ObjectID。detail 接口用 nodeId 定位节点后再解析业务 ObjectID。

2. NodeID 从哪来

2.1 数据库表

表 库 字段 说明
Tree messys NodeID 菜单节点主键
Tree messys ParentID 父节点 NodeID（根为 0）
UniqueNO messys No 下一个可用 NodeID（NName='tree'）

2.2 MES 新建节点时的分配逻辑

MES 通过 TreeServiceImpl.getNextNodeIdForTree() 从 UniqueNO 表取号：

  1. 悲观锁查询 UniqueNO 中 NName='tree' 的记录（PESSIMISTIC_WRITE）
  2. 取当前 No 作为新 NodeID
  3. 将 No + 1 写回，占用该编号

2.3 触发 NodeID 分配的操作

新增菜单节点 TreeServiceImpl.addNode 先 getNextNodeIdForTree()，再写 Tree
sys_menu 同步 TreeServiceImpl.syncFromSysMenu 每个同步节点分配新 NodeID
复制菜单 TreeServiceImpl.copyMenu 源节点及子树每个节点各分配新 NodeID
交接班菜单批量创建 createShiftLogDispatchMenus → addNode 同上

2.4 EOS 原生 / 历史数据

在 MES 介入之前，NodeID 可能由 EOS 客户端或其他工具写入 Tree，同样依赖 UniqueNO 序列或历史遗留编号。MES 只保证新增/同步/复制时走 getNextNodeIdForTree() 逻辑。

2.5 NodeID 在 Functions 中的用途

Tree.Functions 字段保存菜单跳转 URL，其中 menuId 参数值为 NodeID（不是 ObjectID）。例如同步 sys_menu 时：

复制菜单时，TreeServiceImpl 会将 Functions 里的 menuId=旧NodeID 替换为 menuId=新NodeID。

2.6 NodeID 生命周期

  • 查询：treeDao.findAll(...)、queryObject(nodeid) 等
  • 删除：delete / deleteBatch 按 NodeID 删除 Tree，并先 ObjectRegisterDao.deleteByOwnerId(NodeID) 清理关联对象

3. ObjectID 是什么

ObjectID 是 EOS 对象注册表 messys.dbo.ObjectRegister 的主键。每个可授权对象在 ObjectRegister 中注册一条记录；菜单/目录节点对应 TypeID = 7，并通过 OwnerID = Tree.NodeID 与菜单树关联。

MES 维护菜单时会将 ObjectID 冗余写入 Tree.ObjectID，便于权限树接口一次查询带出。

在角色菜单授权场景下，前端勾选菜单后提交的是 objectId 列表，写入 mesdata.dbo.STPermission.ObjectID（配合 UserID=角色 OID、Oprate=「执行」、Permission=1）。

4. ObjectID 从哪来

4.1 数据库表

层级 库/表 字段 含义
权威主键 messys ObjectRegister ObjectID 全局对象 ID（自增：MAX+1）
关联 messys ObjectRegister OwnerID = Tree.NodeID
类型 messys ObjectRegister TypeID MES 新建菜单固定为 7（菜单/目录）
冗余 messys Tree ObjectID 与 ObjectRegister.ObjectID 一致
授权 mesdata STPermission ObjectID 引用 ObjectRegister.ObjectID

关系：Tree.NodeID ← ObjectRegister.OwnerID；Tree.ObjectID = ObjectRegister.ObjectID。

4.2 MES 新建节点时的分配逻辑

TreeServiceImpl.saveObjectRegisterForTree()：

  1. ObjectRegisterDao.findMaxObjectId() 取 MAX(ObjectID) + 1
  2. 插入 ObjectRegister（TypeID=7，OwnerID=NodeID，Object=菜单名）
  3. 将返回的 ObjectID 写入 Tree.ObjectID

与 NodeID 分配在同一事务内完成（如 addNode 先取 NodeID，再创建 ObjectRegister）。

4.3 触发 ObjectID 分配的操作

与 NodeID 分配的操作相同（新增、同步、复制）。复制菜单时 NodeID 与 ObjectID 均重新分配，不会沿用源节点的 ObjectID。

场景 ObjectID 来源
MES 新增 EOS 菜单节点 saveObjectRegisterForTree 新分配
从 sys_menu 同步 每个同步节点一条新 ObjectRegister
复制菜单 新 NodeID + 新 ObjectRegister + 新 ObjectID
EOS 原生/历史数据 可能由 EOS 客户端写入；Tree.ObjectID 可能已存在
失败兜底 object == null 时 Tree.ObjectID = 0（无有效授权对象）

5. NodeID 与 ObjectID 对照

对比项 NodeID ObjectID
所属表 messys.Tree 主键 messys.ObjectRegister 主键，冗余在 Tree.ObjectID
分配方式 UniqueNO（NName=’tree’）递增 MAX(ObjectID)+1
前端 zTree 字段 id objectId
是否用于 STPermission「执行」 否 是
复制菜单 重新分配 重新分配

5.1 业务 ObjectID 与 NodeID 的非 OwnerID 关联

菜单授权与 ERP 按钮授权使用不同的 ObjectID，且业务对象的 OwnerID 不一定等于 Tree.NodeID。

场景 ObjectID 示例 TypeID OwnerID STPermission 用途
菜单对象 468 7 430 Oprate=执行, Permission=1
业务对象 965 1 null Oprate=EX61:..., Permission=0

解析路径（EosMenuObjectResolver.resolveBusinessObjects）：

  1. ObjectRegister.OwnerID = NodeID 且 TypeID != 7
  2. Tree.Functions 括号内单据名 + 菜单对象名 → DjDy.DjCName → ObjectRegister.Object = DjCName 且 TypeID != 7
  3. 回退：Tree.ObjectID 对应 ObjectRegister（可能含 TypeID=7）

禁止仅用 OwnerID=NodeID 或 Tree.ObjectID 推断按钮授权 ObjectID。复合页可能返回多个业务 ObjectID；同一 ObjectID 上可有多个 EXxx: 按钮 Oprate。

listAvailableOperations：标准操作 + ExFunction EXxx: + 库中已有非「执行」Oprate。

示例（NodeID=430）：菜单树 objectId=468 用于勾选「执行」；按钮 EX61:组织架构分发 写在 ObjectID=965。

  2. EosRoleObjectPermissionServiceImpl.saveMesAndObjectPermissions(request) — ERP 操作 + MES 按钮

mode=replace 时：先按该角色已有「执行」的 ObjectID 删除这些 ObjectID 下全部 Oprate 行，再插入勾选的「执行」；mesMenuIds 与 mesButtonMenuIds 都为空时不改动 sys_role_menu。

说明：Tree.Functions 里 URL 的 menuId= 是 EOS NodeID（页面跳转用）；sys_menu.menu_id 的权威映射在 **mesdata.sys_menu_eos_node**（eos_node_id → menu_id），由 syncFromSysMenu 写入或 backfillSysMenuEosNode 按 URL/NodeDesc 回填。过渡期仍双写 NodeDesc=MES_MENU:{sysMenuId} 作兼容 fallback。

瘦身密码（五）：甜蜜陷阱——肥胖引爆的八大健康地雷

肥胖是健康的「隐形杀手」——影响的不只是外形，而是心血管、代谢、内分泌、呼吸、骨骼、生殖乃至心理的全系统连锁反应。以下梳理书中重点阐述的八大健康地雷及应对思路。

1. 糖尿病：胰岛素遇上甜甜圈

中国 20～79 岁人群糖尿病患病率约 10.6%，患病人数约 1.41 亿。肥胖与糖尿病如影随形：

  • 体重每增加 1 kg，糖尿病风险至少升 5%
  • 约 50% 肥胖者将来可能患 2 型糖尿病
  • 糖尿病患者中约 2/3 超重或肥胖

机制：内脏脂肪像「棉袄」包裹细胞，胰岛素（钥匙）难以与受体（锁）结合，葡萄糖进不了细胞 → 胰岛素抵抗 → 代偿性高胰岛素 → 食欲增加 → 更胖 → 最终血糖失控。

逆转密码：

  • 少吃深加工食品、奶茶炸鸡；多吃蔬菜、粗粮
  • 中低强度有氧运动，餐后 30～60 分钟，每次 ≥30 分钟，约 200～300 千卡
  • 超重人群 35～70 岁应每 3 年筛查血糖
  • 九体医学统计：气虚质、阴虚质、痰湿质最易患糖尿病

2. 冠心病：糖脂风暴下的冠状动脉

冠心病患者超重/肥胖率超 50%。BMI 越高，冠心病发病率越高；肥胖者患病概率约为常人 2～3 倍，超平均体重 40% 者死亡风险翻倍。

机制：肥胖 → 血脂紊乱 → 动脉粥样硬化斑块 → 冠脉狭窄 → 心肌缺血。心脏如同小发动机驱动重型卡车，长期超负荷终将「罢工」。

逆转密码：减重 + 控脂 + 戒烟限酒 + 规律运动；编写细胞层面的「燃脂程序」，减轻心脏负担。

3. 睡眠呼吸暂停：内脏脂肪的午夜叛乱

腹型肥胖者脂肪堆积在呼吸道周围，气道变窄，睡眠时呼吸暂停 → 缺氧 → 睡眠质量差 → 日间嗜睡 → 活动减少 → 更胖，形成死亡循环。

逆转密码：减重是核心；侧睡、避免睡前饮酒；严重者需呼吸机等医学干预。

4. 脂肪肝：内脏的「垃圾处理厂」瘫痪

超重/肥胖者并发症中，脂肪肝最常见之一。肝脏本应将脂肪打包运出，糖尿病与肥胖使这一过程效率降低，脂肪在肝内堆积。

常见认知陷阱（书中强调）：

  • 「不胖就不会脂肪肝」——瘦人脂肪肝也不少见
  • 「无症状就不用管」——可进展为肝纤维化
  • 「只吃素就能好」——关键在于总能量与代谢
  • 「护肝片够用了」——病因不除，难以逆转

逆转密码：减重 5%～10% 常可显著改善肝脂肪变；控糖控脂 + 运动。

5. 骨关节炎：关节的载荷安全阈值

体重每增加 1 kg，膝关节承受压力约增加 3～4 kg。肥胖 → 慢性炎症 → 软骨磨损加速。

逆转密码：减重减轻关节负荷；水中运动、肌力训练增强关节稳定性。

6. 多囊卵巢综合征：激素风暴

肥胖与多囊卵巢相互加剧：脂肪组织干扰激素平衡，胰岛素抵抗推高雄激素，影响排卵与生育。

逆转密码：减重 5%～10% 可显著改善月经与排卵；生活方式干预是一线治疗。

7. 乳腺癌：癌变风险的土壤

肥胖改变雌激素等激素水平，脂肪组织释放炎症因子，为癌细胞生长提供「土壤」。腹型肥胖与多种妇科、消化道肿瘤风险相关。

逆转密码：保持健康体重、规律筛查、减少久坐。

8. 心理沼泽：身材焦虑与情绪雪崩

肥胖与心理相互纠缠：

  • 自尊心、自我形象受损
  • 焦虑 → 暴食 → 更胖 → 更焦虑
  • 脂肪组织炎症因子可能影响大脑情绪通路
  • 社会偏见与「体型歧视」加重心理负担
  • 极端节食或暴食交替，饮食成为情绪的「翻译器」

逆转密码：接纳与改变并行；寻求心理咨询；用运动、社交替代情绪性进食；体重管理应是关爱自己，而非自我惩罚。

不同体质易患不同慢病，调理应有的放矢：

体质 相关风险
痰湿质 肥胖、高血压、糖尿病、高血脂
气虚质 感冒、内脏下垂、乏力
阳虚质 畏寒、腹泻、痹证
阴虚质 失眠、咽痛、「三高」
血瘀质 肿瘤、痛证、卒中
气郁质 甲状腺、乳腺疾病、情绪障碍

体质可调——在并发症尚未形成前调体，是最好的「逆转密码」。

系列结语

《瘦身密码》传递的核心信息可以概括为三句话：

  1. 中国肥胖形势严峻，腰围与 BMI 同样值得每日关注
  2. 科学减肥是马拉松，忌节食、代餐、极端断食
  3. 九体医学提供个体化路径——先识体质，再管体重，方能健康瘦身不反弹

2024 年国家「体重管理年」已经启程。愿我们都不再以「换大码裤子」为常态，而是在读懂自己身体密码的基础上，走出属于自己的健康之路。

瘦身密码（四）：九大体质科学甩肉指南——管体加管重

核心理念：管体 + 管重

  • 管体：辨识体质、纠正偏颇——体质调好了，赘肉才不容易反弹
  • 管重：吃对食物比盲目少吃更重要；体重是体质的一面镜子，但不是唯一指标

同样体重的人，体脂率、肌肉量不同，健康状况可以天差地别。短期节食难持久，结合体质的长期调理才是正道。

平和质：别把好体质作没了

特征：体形匀称，精力充沛，患病少，适应力强。

要点：

  • 膳食平衡，粗粮细粮搭配，寒温适中，七八分饱
  • 每天有氧运动约 30 分钟，或步行不少于 6000 步
  • 22:30 前入睡，春夏养阳、秋冬避风寒
  • 穴位保健：足三里、三阴交、涌泉

药膳举例：南瓜豆腐羹、芝麻山药粥

阳虚质：扶阳驱寒是关键

特征：怕冷、手足凉、夜尿多、精神不振，脂肪像给身体「穿羽绒服」。

要点：

  • 避寒就温，多晒太阳，睡前 40～45℃ 泡脚 15 分钟
  • 宜羊肉、鸡肉、韭菜、核桃；少生冷、少苦寒苦瓜（可煮透减寒）
  • 运动选慢跑、太极拳、八段锦，微汗为度，忌大汗伤阳
  • 穴位：关元、命门、阳池

药膳举例：暖胃茶（红茶+桂圆+生姜+白术+红枣）、当归生姜羊肉汤

阴虚质：补水降火是核心

特征：口干咽燥、手足心热、盗汗、便干，体型偏瘦但血脂易偏高。

要点：

  • 忌熬夜、桑拿、高温环境；室温 14～26℃ 为宜
  • 宜芝麻、蜂蜜、豆腐、鱼类；少辛辣燥烈、火锅
  • 运动选游泳、瑜伽、散步，避免大汗淋漓
  • 穴位：太溪、三阴交、大敦

药膳举例：三汁饮（黄精、生地、天门冬、茯苓）、冰糖五果羹

气郁质：疏肝解郁才能瘦

特征：多愁善感、胸闷叹息、睡眠差；一焦虑就暴食，压力肥堆腰腹。

要点：

  • 环境宜安静，春季多户外活动舒展阳气
  • 宜萝卜、洋葱、柑橘；玫瑰花、茉莉花代茶饮
  • 少芋艿、甘薯等易胀气食物
  • 推荐：玫瑰花茶 + 敲胆经，疏解肝郁

血瘀质：活血化瘀加速瘦身

要点：

  • 少食肥腻、寒凉，宜活血食物：山楂、黑豆、玫瑰花
  • 运动促进血液循环，避免久坐
  • 药浴泡脚 + 山楂茶是经典组合
  • 穴位：血海、膈俞、三阴交

痰湿质：祛湿排浊才是真抽脂

特征：体胖腹大、身重困倦、痰多、鼾声大，减肥易卡平台期。

要点：

  • 饮食清淡：冬瓜、白萝卜、薏米、赤小豆；少甜腻、少暴饮暴食
  • 忌潮湿环境，宜阳光下午后运动

瘦身密码（三）：九体医学入门——解锁你的体质密码

世界上没有两片相同的树叶

九体医学以九种体质分类为指导，研究体质特征与疾病的相关性，从而指导预防、治疗与养生康复。王琦院士将人群科学分为九种类型：

九体医学与精准医学

2015 年，王琦院士团队提出「九体医学健康计划」，被视为中国版「精准医学」：与奥巴马「精准医学」计划同年亮相，却更强调中医「治未病」「同病异治」思想。

  • 体质辨识已纳入《国家基本公共卫生服务标准》
  • 《中医体质分类与判定》量表已翻译成英、日、韩等多国语言
  • 覆盖全国 31 个省区，应用于健康管理、亚健康调理、慢病防控

古籍早有端倪：「肥人多痰湿」（朱丹溪）、「阴阳匀平……命曰平人」（《素问》）。王琦院士用 40 余年研究，将零散珍珠串成体系。

四大原理

  1. 体质过程论：体质随年龄阶段演变，养生应因时而异
  2. 形神构成论：躯体与心理一体，痰湿质者情绪稳定型居多
  3. 环境制约论：饮食、气候、地理塑造体质——嗜肥甘生痰湿，过逸成痰瘀
  4. 禀赋遗传论：先天禀赋决定体质底色，后天仍可调节

三大核心

  • 体质可分论：个体差异与群体趋同性并存
  • 体病相关论：痰湿质易患肥胖、三高；气虚质易感冒、内脏下垂；血瘀质易患肿瘤、痛证
  • 体质可调论：偏颇体质可通过饮食、起居、运动、情志干预改善

与肥胖的关系

肥胖与体质密切相关：

  • 痰湿质：中心性肥胖、高血脂、高血糖、高血压高发——「祛湿排浊才是真抽脂」
  • 气虚质：肉松垮、动则气短，减肥效率低
  • 阳虚质：怕冷，脂肪像「穿羽绒服」保温
  • 气郁质：压力肥，焦虑时暴食，肉易堆腰腹
  • 湿热质：脸油肚凸，「油胖子」需清火除湿
  • 血瘀质：肉硬、循环差，减肥像挤牙膏

国家 2024 年「体重管理年」方案明确发挥中医药技术优势；王琦院士「九体医学健康中国计划」正是体重个体化管理的理论基础。

如何判定自己的体质？

依据《中医体质分类与判定》标准：

平和质：转化分 ≥60，且其余 8 种均 <30（或均 <40 为「基本是」）

偏颇质：转化分 ≥40 为「是」；30～39 为「倾向是」

建议通过正规医疗机构或社区卫生中心的体质辨识服务获取准确结果，勿仅凭网络测试下定论。

体质不是终身标签

体质会随环境、饮食、情绪变化而调整。一方水土养一方人，养生需因人制宜、因时制宜——读懂身体密码，才能把健康主动权握在自己手里。

瘦身密码（二）：脂肪工厂的运作密码——科学减肥是场马拉松

你真的需要减肥吗？

BMI：有用，但不万能

中国成人标准：

分类 BMI
体重过低 <18.5
正常 18.5～24
超重 24～28
肥胖 ≥28

BMI 对普通成年人实用，但对运动员等肌肉发达者可能误判；对孕妇、儿童、老年人参考价值有限。更关键的是脂肪分布，而非单一数字。

肥胖三级预警

  • 轻度（28～32.5）：糖尿病、高血压风险上升，关节负担加重
  • 中度（32.5～37.5）：心血管风险加剧，易出现睡眠呼吸暂停
  • 重度（≥37.5）：心衰、脑卒中风险极高，代谢综合征与多种癌症风险显著上升

体脂率与腰臀比

健康体脂率：男性约 15%～20%，女性约 20%～25%。腰臀比反映脂肪分布——苹果型（腹型）远比梨型危险。

脂肪从哪来？

中医视角：易胖体质的「培育土壤」

  1. 饮食不节：肥甘厚味、暴饮暴食，脾胃运化不及，聚为膏脂痰浊
  2. 缺乏运动：久坐少动，气血不畅，痰湿内生
  3. 情志失调：肝郁气滞、思虑伤脾，水湿代谢失常
  4. 脏腑失调：脾虚运化失司、肾阳虚水湿不化

西医视角：代谢失衡

遗传、高热量饮食、运动不足、内分泌疾病（甲减、库欣综合征）、肠道菌群失衡等，共同导致能量摄入大于消耗，多余能量以脂肪储存。

快速瘦身的陷阱

过度节食：得不偿失

节食初期体重下降，但身体会降低基础代谢率（BMR）进入「平台期」。恢复正常饮食后极易反弹，并可能带来：

  • 免疫力下降、肝肾功能失调
  • 女性月经紊乱甚至闭经
  • 脱发、抑郁焦虑
  • 反复节食形成恶性循环

BMR 估算公式（Mifflin-St Jeor）：

  • 男性：10×体重(kg) + 6.25×身高(cm) − 5×年龄 + 5
  • 女性：10×体重(kg) + 6.25×身高(cm) − 5×年龄 − 161

代餐、排毒、极端断食

  • 代餐：短期降重，但代谢减慢，恢复饮食后易反弹，长期可能影响消化与免疫
  • 排毒：人体有自净能力；情志调节、均衡饮食、规律运动才是正道
  • 轻断食：间歇性禁食有一定研究支持，但长时间不吃饭可能导致低血糖、电解质紊乱，糖尿病患者尤其危险

什么才是科学减肥？

核心原则：减肥是马拉松，不是百米冲刺。

能量平衡

活动因子：久坐 1.2，轻度活动 1.375，中度 1.55，高度 1.725，极高 1.9。

三大营养素分配

  • 碳水化合物：45%～65%（优选全谷物、薯类、豆类）
  • 蛋白质：10%～35%（瘦肉、鱼、蛋、奶、豆制品）
  • 脂肪：20%～30%（植物油、坚果，少饱和脂肪与反式脂肪）

饮食习惯

  • 定时进食，细嚼慢咽，七八分饱
  • 进食顺序：清汤 → 蔬菜 → 肉类 → 主食
  • 烹调以蒸、炖、煮为主，少油炸
  • 看懂营养成分表，警惕「低脂」但高热量的食品

运动：每天 6000 步起步

  • 每周至少 150 分钟中等强度有氧运动
  • 结合力量训练，提高基础代谢
  • 碎片化运动也有价值：通勤多走、爬楼梯、工间拉伸

情绪管理

压力肥、深夜暴食常与情绪相关。好心情是最佳「燃脂剂」——学会与焦虑和解，比盲目节食更重要。

懒人减肥武器库速览

维度 要点
饮食 能量赤字 + 营养充足；外卖少点高糖高油；麻辣烫不加麻酱也是多样饮食的好选择

瘦身密码（一）：中国式发福图鉴——14亿人的体重失控现场

近三十年，中国人以惊人速度「胖」了起来。据《中国居民营养与慢性病状况报告（2020）》，成年居民超重率 34.3%、肥胖率 16.4%——每 2 个成年人就有 1 人面临超重/肥胖威胁。

更令人警醒的是增速：1989 年中国超重人口约 1.67 亿，2009 年增至 5.29 亿，20 年间每天约增加 4.9 万人，年均增长率 10.8%，超过同期 GDP 增速。《柳叶刀》估算，2021 年全球超重/肥胖成年人 21.1 亿，中国以 4.02 亿居首；预计到 2050 年，全球将有超过一半成年人超重/肥胖。

若以腰围衡量腹型肥胖，2009 年中国腹型肥胖人口约 6.7 亿，超过欧美总和。李新华等团队在《柳叶刀》发表的研究显示，2004～2018 年间，18～69 岁人群标准化平均 BMI 从 22.7 升至 24.4 kg/m²，肥胖患病率（BMI≥30）从 3.1% 升至 8.1%。2018 年肥胖人数约 8500 万，是 2004 年的三倍。

谁更容易发胖？

肥胖增长并非均匀分布，城乡、性别、年龄各有特点：

维度 主要趋势
城乡 2010 年前城市高于农村；此后农村女性 BMI 增速快于城市，2018 年农村女性已超过城市
性别 2004 年男性低于女性，2018 年完全逆转，男性增速更快
年龄 女性随年龄升高至 50 岁；男性 30～49 岁为高峰
儿童 与 1985 年比，2014 年 7～18 岁学生肥胖患病率增长 54.8 倍
老年人 2011～2015 年超重率 29.2%→33.2%，中心性肥胖 58.3%→63.9%

肥胖正在吃掉你的存款

肥胖已从个人问题演变为国家危机。2024 年 6 月，国家卫生健康委联合 16 部门启动「体重管理年」活动，推动慢病防治关口前移。

健康代价：

  • 近 20 年高血压患病率 19%→28%，糖尿病约 3%→13%
  • 2018 年糖尿病及前期患病率合计约 51%，知晓率、治疗率、控制率均偏低
  • 预测 2030 年成人超重/肥胖率或达 70.5%

经济代价：

  • 2030 年归因于超重/肥胖的医疗费用预计约 4180 亿元，约占全国医疗费用 22%
  • 超重/肥胖对全球经济影响占 GDP 2.4%，2035 年预计升至更高
  • 肥胖还带来间接损失：工作效率下降、请假增多、就业机会受影响（「体型歧视」）

研究还发现，肥胖与收入的关系并非线性——中等收入人群肥胖风险反而最高；农村高收入男性、高教育男性肥胖关联更强，而女性高教育与肥胖呈负相关。

腰围比体重更值得警惕

BMI 虽常用，但有盲区：不区分肌肉与脂肪、不反映脂肪分布。腹型肥胖（苹果型）风险远高于梨型：

  • 男性腰围 ≥90 cm、女性 ≥85 cm，即存在腹型肥胖风险
  • 内脏脂肪升高甘油三酯、胆固醇，促动脉粥样硬化
  • 干扰胰岛素作用，显著增加 2 型糖尿病风险
  • 与结直肠癌、子宫内膜癌等多种癌症相关
  • 压迫横膈膜，引发睡眠呼吸暂停；加重关节负担

建议： 除定期测 BMI 外，务必关注腰围和腰臀比（亚洲男性上限 0.9，女性 0.8）。

写在最后

肥胖威胁的不只是外形，更是心血管、代谢、呼吸、骨骼乃至心理的全方位健康。2024 年「体重管理年」与「九体医学健康中国计划」的推进，标志着体重管理正从「一刀切节食」走向个体化、科学化、中西医协同的新阶段。
