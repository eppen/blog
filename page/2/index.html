EOS 菜单与角色关联关系说明

本文档说明 MES 项目中 EOS 原生权限体系与 MES Web RBAC 的关系，以及角色、菜单数据分别存储在哪里、如何保存关联。

2026-07-31 更新：按当前代码实现修订。eosrole 已映射并读写 **STPermission**（菜单「执行」+ ERP 对象操作）与 **STUserGroup**（用户-角色）；MES Web 按钮权限写入 **sys_role_menu**。核心授权表仍为 **mesdata.dbo.STPermission**。

关联文档：EOS 菜单树 NodeID 与 ObjectID 说明

结论摘要

**在本项目（mes-parent）中，EOS 角色 ↔ 菜单授权可由 MES eosrole「配置菜单权限」写入 STPermission**；也可在 EOS 原生安全管理器中配置。用户 ↔ 角色由 eosrole「配置用户权限」双写 STUserGroup + sys_user_role。

能力 库 表 MES 是否实现
EOS 用户/角色 mesdata STUsers（uGroup=0/1） 角色 CRUD（eosrole）
用户 ↔ 角色 mesdata STUserGroup 已映射，由 EosRoleUserServiceImpl 管理（双写 sys_user_role）
角色 ↔ 菜单 mesdata STPermission 已映射，由 EosRolePermissionServiceImpl / EosRoleObjectPermissionServiceImpl 读写
EOS 菜单树 messys Tree + ObjectRegister eostree 维护/同步
EOS 角色 → MES 角色 mesdata sys_role（eos_role_id） 同步元数据；权限保存时也可自动 syncRole
MES 角色 → MES 菜单/按钮 mesdata sys_role_menu 角色管理页面；eosrole 保存 MES 按钮时亦写入
EOS NodeID → MES menu_id mesdata sys_menu_eos_node sync/backfill/copy 写入

EOS 原生权限生效链路：

1. EOS 侧数据模型

1.1 用户与角色：STUsers（mesdata）

角色与用户共用 mesdata.dbo.STUsers，通过 uGroup 区分：

uGroup 含义
0 用户
1 角色

相关代码：StusersEntity、StusersServiceImpl.saveRole / updateRole、EosRoleController（路径 /eosrole）。

eosrole 页面「保存角色」只写角色基本信息（编码、名称、描述、分组 Categories、启用状态），不涉及菜单勾选。菜单与对象操作权限在「配置菜单权限」弹窗中单独保存（见 §2.3）；用户分配在「配置用户权限」中保存（见 §2.5）。

EmpowermentRight、RelateUserH 等字段在 MES 新增角色时仅填默认值，不用于菜单授权；菜单授权走 STPermission。

1.2 用户-角色：STUserGroup（mesdata）

字段 含义
UserID 用户 OID（STUsers.OID，uGroup=0）
GroupID 角色 OID（STUsers.OID，uGroup=1）
Back 备注

MES 已映射：StUserGroupEntity + EosRoleUserServiceImpl。eosrole「配置用户权限」保存时：

  1. 清空该角色在 STUserGroup 中的旧关联，再批量插入新用户
  2. 按 STUsers.UserID ↔ sys_user.username 匹配 MES 用户；有 MES 用户时先 ensureMesRole，再全量改写 sys_user_role

也可在 EOS 原生安全管理中分配角色（同样写入 STUserGroup）。

1.3 菜单：Tree + ObjectRegister（messys）

表 库 作用
Tree messys EOS Web 菜单树（NodeID、ParentID、NodeCaption、Functions 等）
ObjectRegister messys 对象注册；OwnerID = Tree.NodeID，TypeID = 7 表示菜单/目录
UniqueNO messys 分配 Tree 的 NodeID（NName='tree'）

新增菜单节点时（TreeServiceImpl.addNode）会：

  1. 从 UniqueNO 分配新 NodeID
  2. 写入 Tree
  3. 写入 ObjectRegister，并将返回的 ObjectID 回填到 Tree.ObjectID

从 MES 同步菜单时（TreeServiceImpl.syncFromSysMenu），同样会为每个节点创建 ObjectRegister 记录。

1.4 角色-菜单关联：STPermission（mesdata）

核心授权表。EOS 原生安全管理器与 MES eosrole「配置菜单权限」保存时均写入此表。

字段 类型 含义
UserID int STUsers.OID；绝大多数为角色（uGroup=1），少量为用户直授（uGroup=0）
ObjectID int messys.dbo.ObjectRegister.ObjectID
Oprate nvarchar 操作类型（见下表）
Permission int 权限值；含义随 Oprate 类型不同（见下表）

ERP 模式下 Permission 双语义（本环境 WebPermission 未启用，按钮授权均走 STPermission）：

Oprate 类型 示例 Permission 含义
菜单 执行 1 允许可见（白名单；无记录=不可见）
按钮/操作 增加、EX61:组织架构分发 0 禁用（黑名单；无记录=允许）

常见 Oprate 取值：执行（菜单）；标准操作（增加、修改、删除、审核…）；自定义 EX{ExFunction.ID}:{SDesc}（如 EX61:组织架构分发）。

2. MES 侧数据模型

2.1 角色-菜单：sys_role_menu

MES Web「角色管理」（role.html + role.js）通过 zTree 勾选菜单，提交 menuIdList 到 /sys/role/save 或 /sys/role/update。

保存逻辑（SysRoleMenuServiceImpl.saveOrUpdate）：

  1. 按 role_id 删除原有关联
  2. 批量插入新的 (role_id, menu_id) 记录

权限生效链路：

eosrole 保存 MES 菜单/按钮时也会写入同一张表（见 §2.3）。

2.2 EOS 角色同步到 MES

EosRoleSyncServiceImpl / 定时任务 EosTask.sycnEosRole() 调用：

  • sysRoleService.saveWithoutMenu() — 新建 MES 角色
  • sysRoleService.updateWithoutMenu() — 更新 MES 角色

同步字段：角色名、描述、分组、eos_role_id。定时/手动同步本身不会同步 EOS STPermission 或 MES sys_role_menu。

若在 eosrole「配置菜单权限」中提交了 mesMenuIds / mesButtonMenuIds，且尚无对应 MES 角色，会自动 syncRole 后再写 sys_role_menu。

2.3 eosrole「配置菜单权限」

eosrole 弹窗支持统一配置：

菜单类型 识别 保存位置
ERP 原生 Functions 不含「函数打开网页」（menuType=erp） 菜单 → STPermission（Oprate=执行, Permission=1）；按钮 → STPermission（EXxx:... 等, Permission=0=禁用）
MES Web Functions 含「函数打开网页」（menuType=mes），sys_menu_eos_node 存 menu_id ↔ eos_node_id 菜单执行 → STPermission；按钮 → sys_role_menu
目录 menuType=folder 通常仅作树结构；勾选子节点时汇总子菜单 objectId

相关 API（EosRoleController，权限 eosrole:permission）：

方法 路径 作用
* /eosrole/menu/tree 权限菜单树（含 objectId / menuType / sysMenuId）
GET /eosrole/permission/{roleId} 已授权菜单 objectId（执行+Permission=1）
GET /eosrole/permission/detail/{roleId}?nodeId= 节点对象/按钮权限详情
GET /eosrole/permission/mes-menu-ids/{roleId} 回显 MES 角色全部 sys_role_menu menuId
POST /eosrole/permission/save 保存菜单执行 + ERP 操作 + MES 按钮
* /eosrole/menu/backfill-mes-menu-id 历史 MES 节点回填 sys_menu_eos_node

POST /eosrole/permission/save body（EosRolePermissionSaveRequest）：

字段 说明
roleIds EOS 角色 OID 列表
objectIds 勾选菜单的 Tree.ObjectID → STPermission「执行」
mode append / replace
mesMenuIds MES 目录/菜单 menu_id → sys_role_menu
mesButtonMenuIds MES 按钮 menu_id → sys_role_menu
operationPermissions {objectId, oprate, granted}；ERP 禁止列表（granted=false 写 Permission=0）
operationReplaceObjectIds replace 时需清理非「执行」权限的业务 ObjectID

保存流程：

  1. EosRolePermissionServiceImpl.savePermissions(roleIds, objectIds, mode) — 写菜单「执行」
  2. EosRoleObjectPermissionServiceImpl.saveMesAndObjectPermissions(request) — ERP 操作 + MES 按钮

mode=replace 时：先按该角色已有「执行」的 ObjectID 删除这些 ObjectID 下全部 Oprate 行，再插入勾选的「执行」；mesMenuIds 与 mesButtonMenuIds 都为空时不改动 sys_role_menu。

说明：Tree.Functions 里 URL 的 menuId= 是 EOS NodeID（页面跳转用）；sys_menu.menu_id 的权威映射在 **mesdata.sys_menu_eos_node**（eos_node_id → menu_id），由 syncFromSysMenu 写入或 backfillSysMenuEosNode 按 URL/NodeDesc 回填。过渡期仍双写 NodeDesc=MES_MENU:{sysMenuId} 作兼容 fallback。

建表与历史迁移脚本：sys_menu_eos_node.sql、sys_menu_eos_node.mysql.sql（位于 mes-security-eos 模块 doc/）。

2.4 MES 菜单管理「设置到 EOS」

MES 菜单管理页（sys/menu）勾选目录/菜单后点击「设置到 EOS」，调用 POST /tree/syncFromSysMenu（menu.js#setToEos）。

步骤 行为
1 用户选择 EOS 目标目录 parentNodeId
2 TreeServiceImpl.syncFromSysMenu 为每个 type=0/1 的 sys_menu 新建 EOS Tree 节点
3 applySysMenuMapping 写入 sys_menu_eos_node，并双写 NodeDesc=MES_MENU:{sysMenuId}（目录与菜单均写）
4 type=1 且有 url 时，Functions 生成 MES Web 跳转 URL，其中 menuId= 为新分配的 EOS NodeID

历史已同步但未写映射的节点，可任选以下方式处理（当前 sync 始终新建节点，不更新旧节点）：

方式 说明
定时任务 EosTask.backfillSysMenuEosNode，默认每日 3:00（t_qrtz_schedule_job；升级见 V2__Update_backfill_sys_menu_eos_node_job.sql）
手动接口 /eosrole/menu/backfill-mes-menu-id
重新同步 菜单管理页「设置到 EOS」（会新建节点）
SQL 迁移 执行 sys_menu_eos_node.sql 从 NodeDesc 导入历史映射

定时任务与手动接口共用 TreeService.backfillSysMenuEosNode()。局限：仅对尚无映射记录的节点回填；URL 匹配仅适用于 Functions 含「函数打开网页」的 MES Web 菜单；type=0 目录（Functions 为空）若 NodeDesc 也无映射，需重新「设置到 EOS」。

6. 运维与开发建议

  1. EOS 客户端菜单权限：可在 EOS 原生安全管理中配置，也可在 MES eosrole「配置菜单权限」中配置；数据均写入 mesdata.dbo.STPermission。运维排查可用上文 SQL。
  2. MES 页面权限：可在「系统管理 → 角色管理」勾选 sys_menu；也可在 eosrole 中为 MES Web 菜单勾选按钮（写入同一 sys_role_menu）。菜单「执行」可见性仍依赖 STPermission。
  3. 两套菜单数据源：
    • Tree / ObjectRegister：EOS 客户端 / Web 壳菜单
    • sys_menu：MES 页面与 Shiro 权限
    • eosrole 可在同一弹窗统一配置两侧，但没有从 STPermission 自动全量同步到 sys_role_menu（或反向）的后台任务；MES 按钮仅在 eosrole 保存时写入。
  4. 从 EOS 同步角色后：若需在 MES Web 中使用该角色的菜单/按钮，可在角色管理中分配，或在 eosrole 配置菜单权限时一并提交 mesMenuIds / mesButtonMenuIds。
  5. 跨库注意：STUsers、STPermission、STUserGroup、sys_* 在 mesdata；Tree、ObjectRegister 在 messys，关联字段为 STPermission.ObjectID ↔ ObjectRegister.ObjectID。

瘦身密码（五）：甜蜜陷阱——肥胖引爆的八大健康地雷

肥胖是健康的「隐形杀手」——影响的不只是外形，而是心血管、代谢、内分泌、呼吸、骨骼、生殖乃至心理的全系统连锁反应。以下梳理书中重点阐述的八大健康地雷及应对思路。

1. 糖尿病：胰岛素遇上甜甜圈

中国 20～79 岁人群糖尿病患病率约 10.6%，患病人数约 1.41 亿。肥胖与糖尿病如影随形：

  • 体重每增加 1 kg，糖尿病风险至少升 5%
  • 约 50% 肥胖者将来可能患 2 型糖尿病
  • 糖尿病患者中约 2/3 超重或肥胖

机制：内脏脂肪像「棉袄」包裹细胞，胰岛素（钥匙）难以与受体（锁）结合，葡萄糖进不了细胞 → 胰岛素抵抗 → 代偿性高胰岛素 → 食欲增加 → 更胖 → 最终血糖失控。

逆转密码：

  • 少吃深加工食品、奶茶炸鸡；多吃蔬菜、粗粮
  • 中低强度有氧运动，餐后 30～60 分钟，每次 ≥30 分钟，约 200～300 千卡
  • 超重人群 35～70 岁应每 3 年筛查血糖
  • 九体医学统计：气虚质、阴虚质、痰湿质最易患糖尿病

2. 冠心病：糖脂风暴下的冠状动脉

冠心病患者超重/肥胖率超 50%。BMI 越高，冠心病发病率越高；肥胖者患病概率约为常人 2～3 倍，超平均体重 40% 者死亡风险翻倍。

机制：肥胖 → 血脂紊乱 → 动脉粥样硬化斑块 → 冠脉狭窄 → 心肌缺血。心脏如同小发动机驱动重型卡车，长期超负荷终将「罢工」。

逆转密码：减重 + 控脂 + 戒烟限酒 + 规律运动；编写细胞层面的「燃脂程序」，减轻心脏负担。

3. 睡眠呼吸暂停：内脏脂肪的午夜叛乱

腹型肥胖者脂肪堆积在呼吸道周围，气道变窄，睡眠时呼吸暂停 → 缺氧 → 睡眠质量差 → 日间嗜睡 → 活动减少 → 更胖，形成死亡循环。

逆转密码：减重是核心；侧睡、避免睡前饮酒；严重者需呼吸机等医学干预。

4. 脂肪肝：内脏的「垃圾处理厂」瘫痪

超重/肥胖者并发症中，脂肪肝最常见之一。肝脏本应将脂肪打包运出，糖尿病与肥胖使这一过程效率降低，脂肪在肝内堆积。

常见认知陷阱（书中强调）：

  • 「不胖就不会脂肪肝」——瘦人脂肪肝也不少见
  • 「无症状就不用管」——可进展为肝纤维化
  • 「只吃素就能好」——关键在于总能量与代谢
  • 「护肝片够用了」——病因不除，难以逆转

逆转密码：减重 5%～10% 常可显著改善肝脂肪变；控糖控脂 + 运动。

5. 骨关节炎：关节的载荷安全阈值

体重每增加 1 kg，膝关节承受压力约增加 3～4 kg。肥胖 → 慢性炎症 → 软骨磨损加速。

逆转密码：减重减轻关节负荷；水中运动、肌力训练增强关节稳定性。

6. 多囊卵巢综合征：激素风暴

肥胖与多囊卵巢相互加剧：脂肪组织干扰激素平衡，胰岛素抵抗推高雄激素，影响排卵与生育。

逆转密码：减重 5%～10% 可显著改善月经与排卵；生活方式干预是一线治疗。

7. 乳腺癌：癌变风险的土壤

肥胖改变雌激素等激素水平，脂肪组织释放炎症因子，为癌细胞生长提供「土壤」。腹型肥胖与多种妇科、消化道肿瘤风险相关。

逆转密码：保持健康体重、规律筛查、减少久坐。

8. 心理沼泽：身材焦虑与情绪雪崩

肥胖与心理相互纠缠：

  • 自尊心、自我形象受损
  • 焦虑 → 暴食 → 更胖 → 更焦虑
  • 脂肪组织炎症因子可能影响大脑情绪通路
  • 社会偏见与「体型歧视」加重心理负担
  • 极端节食或暴食交替，饮食成为情绪的「翻译器」

逆转密码：接纳与改变并行；寻求心理咨询；用运动、社交替代情绪性进食；体重管理应是关爱自己，而非自我惩罚。

九体视角下的并发症预防

不同体质易患不同慢病，调理应有的放矢：

体质 相关风险
痰湿质 肥胖、高血压、糖尿病、高血脂
气虚质 感冒、内脏下垂、乏力
阳虚质 畏寒、腹泻、痹证
阴虚质 失眠、咽痛、「三高」
血瘀质 肿瘤、痛证、卒中
气郁质 甲状腺、乳腺疾病、情绪障碍

体质可调——在并发症尚未形成前调体，是最好的「逆转密码」。

《瘦身密码》传递的核心信息可以概括为三句话：

  1. 中国肥胖形势严峻，腰围与 BMI 同样值得每日关注
  2. 科学减肥是马拉松，忌节食、代餐、极端断食

瘦身密码（四）：九大体质科学甩肉指南——管体加管重

核心理念：管体 + 管重

  • 管体：辨识体质、纠正偏颇——体质调好了，赘肉才不容易反弹
  • 管重：吃对食物比盲目少吃更重要；体重是体质的一面镜子，但不是唯一指标

同样体重的人，体脂率、肌肉量不同，健康状况可以天差地别。短期节食难持久，结合体质的长期调理才是正道。

平和质：别把好体质作没了

特征：体形匀称，精力充沛，患病少，适应力强。

要点：

  • 膳食平衡，粗粮细粮搭配，寒温适中，七八分饱
  • 每天有氧运动约 30 分钟，或步行不少于 6000 步
  • 22:30 前入睡，春夏养阳、秋冬避风寒
  • 穴位保健：足三里、三阴交、涌泉

药膳举例：南瓜豆腐羹、芝麻山药粥

阳虚质：扶阳驱寒是关键

特征：怕冷、手足凉、夜尿多、精神不振，脂肪像给身体「穿羽绒服」。

要点：

  • 避寒就温，多晒太阳，睡前 40～45℃ 泡脚 15 分钟
  • 宜羊肉、鸡肉、韭菜、核桃；少生冷、少苦寒苦瓜（可煮透减寒）
  • 运动选慢跑、太极拳、八段锦，微汗为度，忌大汗伤阳
  • 穴位：关元、命门、阳池

药膳举例：暖胃茶（红茶+桂圆+生姜+白术+红枣）、当归生姜羊肉汤

阴虚质：补水降火是核心

特征：口干咽燥、手足心热、盗汗、便干，体型偏瘦但血脂易偏高。

要点：

  • 忌熬夜、桑拿、高温环境；室温 14～26℃ 为宜
  • 宜芝麻、蜂蜜、豆腐、鱼类；少辛辣燥烈、火锅
  • 运动选游泳、瑜伽、散步，避免大汗淋漓
  • 穴位：太溪、三阴交、大敦

药膳举例：三汁饮（黄精、生地、天门冬、茯苓）、冰糖五果羹

气郁质：疏肝解郁才能瘦

特征：多愁善感、胸闷叹息、睡眠差；一焦虑就暴食，压力肥堆腰腹。

要点：

  • 环境宜安静，春季多户外活动舒展阳气
  • 宜萝卜、洋葱、柑橘；玫瑰花、茉莉花代茶饮
  • 少芋艿、甘薯等易胀气食物
  • 推荐：玫瑰花茶 + 敲胆经，疏解肝郁

药膳举例：萝卜丝饼、玫瑰佛手茶

血瘀质：活血化瘀加速瘦身

特征：面色晦暗、唇舌黯、黑眼圈，肉硬腿粗，减肥进展慢如「挤牙膏」。

要点：

  • 少食肥腻、寒凉，宜活血食物：山楂、黑豆、玫瑰花
  • 运动促进血液循环，避免久坐
  • 药浴泡脚 + 山楂茶是经典组合
  • 穴位：血海、膈俞、三阴交

痰湿质：祛湿排浊才是真抽脂

特征：体胖腹大、身重困倦、痰多、鼾声大，减肥易卡平台期。

要点：

  • 饮食清淡：冬瓜、白萝卜、薏米、赤小豆；少甜腻、少暴饮暴食
  • 忌潮湿环境，宜阳光下午后运动
  • 按揉丰隆、足三里、中脘；红豆薏米汤、山药冬瓜汤
  • 古籍云：「肥人多痰湿」——祛湿比单纯节食更关键

湿热质：清火除湿瘦成清爽

特征：面油痤疮、口臭、便黏，脸油肚凸的「油胖子」。

要点：

  • 宜冬瓜、绿豆、苦瓜、芹菜；忌辛辣、油炸、甜腻
  • 运动选中长跑、游泳等耗湿清热项目
  • 冬瓜汤、刮肝经，拒绝油腻感
  • 穴位：阴陵泉、曲池、委中

气虚质：补气提效懒人瘦身

特征：疲乏气短、声低懒言、易感冒，肉松垮像棉花。

要点：

  • 宜山药、大枣、鸡肉、黄芪；忌过劳、过饱
  • 运动从散步、八段锦入手，循序渐进，忌大汗
  • 黄芪水 + 八段锦，提升运化效率再减重
  • 穴位：气海、脾俞、足三里

特禀质：温和调理避开雷区

特征：易过敏，减肥过激易诱发风团、喷嚏。

要点：

  • 低敏饮食，避开已知过敏原
  • 运动环境清洁，避免花粉、尘螨密集处
  • 穴位按摩宜轻柔；中药调理需严格遵医嘱
  • 减肥方案宜缓不宜猛

瘦身密码（三）：九体医学入门——解锁你的体质密码

世界上没有两片相同的树叶

九体医学以九种体质分类为指导，研究体质特征与疾病的相关性，从而指导预防、治疗与养生康复。王琦院士将人群科学分为九种类型：

体质 形象比喻 典型特征（口诀）
平和质 小太阳 气血匀，面红润，目光炯，元气振
气虚质 小懒猫 常气短，虚汗浸，懒言语，易疲晕

平和质是健康基准；其余八种为偏颇体质，如同八条通往特定疾病的道路——早发现、早调体，就能掉头往回走。

九体医学与精准医学

2015 年，王琦院士团队提出「九体医学健康计划」，被视为中国版「精准医学」：与奥巴马「精准医学」计划同年亮相，却更强调中医「治未病」「同病异治」思想。

  • 体质辨识已纳入《国家基本公共卫生服务标准》
  • 《中医体质分类与判定》量表已翻译成英、日、韩等多国语言
  • 覆盖全国 31 个省区，应用于健康管理、亚健康调理、慢病防控

古籍早有端倪：「肥人多痰湿」（朱丹溪）、「阴阳匀平……命曰平人」（《素问》）。王琦院士用 40 余年研究，将零散珍珠串成体系。

四大原理

  1. 体质过程论：体质随年龄阶段演变，养生应因时而异
  2. 形神构成论：躯体与心理一体，痰湿质者情绪稳定型居多
  3. 环境制约论：饮食、气候、地理塑造体质——嗜肥甘生痰湿，过逸成痰瘀
  4. 禀赋遗传论：先天禀赋决定体质底色，后天仍可调节

三大核心

  • 体质可分论：个体差异与群体趋同性并存
  • 体病相关论：痰湿质易患肥胖、三高；气虚质易感冒、内脏下垂；血瘀质易患肿瘤、痛证
  • 体质可调论：偏颇体质可通过饮食、起居、运动、情志干预改善

与肥胖的关系

肥胖与体质密切相关：

  • 痰湿质：中心性肥胖、高血脂、高血糖、高血压高发——「祛湿排浊才是真抽脂」
  • 气虚质：肉松垮、动则气短，减肥效率低
  • 阳虚质：怕冷，脂肪像「穿羽绒服」保温
  • 气郁质：压力肥，焦虑时暴食，肉易堆腰腹
  • 湿热质：脸油肚凸，「油胖子」需清火除湿
  • 血瘀质：肉硬、循环差，减肥像挤牙膏

国家 2024 年「体重管理年」方案明确发挥中医药技术优势；王琦院士「九体医学健康中国计划」正是体重个体化管理的理论基础。

如何判定自己的体质？

依据《中医体质分类与判定》标准：

平和质：转化分 ≥60，且其余 8 种均 <30（或均 <40 为「基本是」）

偏颇质：转化分 ≥40 为「是」；30～39 为「倾向是」

建议通过正规医疗机构或社区卫生中心的体质辨识服务获取准确结果，勿仅凭网络测试下定论。

体质不是终身标签

体质会随环境、饮食、情绪变化而调整。一方水土养一方人，养生需因人制宜、因时制宜——读懂身体密码，才能把健康主动权握在自己手里。

瘦身密码（二）：脂肪工厂的运作密码——科学减肥是场马拉松

你真的需要减肥吗？

BMI：有用，但不万能

中国成人标准：

分类 BMI
体重过低 <18.5
正常 18.5～24
超重 24～28
肥胖 ≥28

BMI 对普通成年人实用，但对运动员等肌肉发达者可能误判；对孕妇、儿童、老年人参考价值有限。更关键的是脂肪分布，而非单一数字。

肥胖三级预警

  • 轻度（28～32.5）：糖尿病、高血压风险上升，关节负担加重
  • 中度（32.5～37.5）：心血管风险加剧，易出现睡眠呼吸暂停
  • 重度（≥37.5）：心衰、脑卒中风险极高，代谢综合征与多种癌症风险显著上升

体脂率与腰臀比

健康体脂率：男性约 15%～20%，女性约 20%～25%。腰臀比反映脂肪分布——苹果型（腹型）远比梨型危险。

脂肪从哪来？

中医视角：易胖体质的「培育土壤」

  1. 饮食不节：肥甘厚味、暴饮暴食，脾胃运化不及，聚为膏脂痰浊
  2. 缺乏运动：久坐少动，气血不畅，痰湿内生
  3. 情志失调：肝郁气滞、思虑伤脾，水湿代谢失常
  4. 脏腑失调：脾虚运化失司、肾阳虚水湿不化

西医视角：代谢失衡

遗传、高热量饮食、运动不足、内分泌疾病（甲减、库欣综合征）、肠道菌群失衡等，共同导致能量摄入大于消耗，多余能量以脂肪储存。

快速瘦身的陷阱

过度节食：得不偿失

节食初期体重下降，但身体会降低基础代谢率（BMR）进入「平台期」。恢复正常饮食后极易反弹，并可能带来：

  • 免疫力下降、肝肾功能失调
  • 女性月经紊乱甚至闭经
  • 脱发、抑郁焦虑
  • 反复节食形成恶性循环

BMR 估算公式（Mifflin-St Jeor）：

  • 男性：10×体重(kg) + 6.25×身高(cm) − 5×年龄 + 5
  • 女性：10×体重(kg) + 6.25×身高(cm) − 5×年龄 − 161

代餐、排毒、极端断食

  • 代餐：短期降重，但代谢减慢，恢复饮食后易反弹，长期可能影响消化与免疫
  • 排毒：人体有自净能力；情志调节、均衡饮食、规律运动才是正道
  • 轻断食：间歇性禁食有一定研究支持，但长时间不吃饭可能导致低血糖、电解质紊乱，糖尿病患者尤其危险

什么才是科学减肥？

核心原则：减肥是马拉松，不是百米冲刺。

能量平衡

活动因子：久坐 1.2，轻度活动 1.375，中度 1.55，高度 1.725，极高 1.9。

三大营养素分配

  • 碳水化合物：45%～65%（优选全谷物、薯类、豆类）
  • 蛋白质：10%～35%（瘦肉、鱼、蛋、奶、豆制品）
  • 脂肪：20%～30%（植物油、坚果，少饱和脂肪与反式脂肪）

饮食习惯

  • 定时进食，细嚼慢咽，七八分饱
  • 进食顺序：清汤 → 蔬菜 → 肉类 → 主食
  • 烹调以蒸、炖、煮为主，少油炸
  • 看懂营养成分表，警惕「低脂」但高热量的食品

运动：每天 6000 步起步

  • 每周至少 150 分钟中等强度有氧运动
  • 结合力量训练，提高基础代谢
  • 碎片化运动也有价值：通勤多走、爬楼梯、工间拉伸

情绪管理

压力肥、深夜暴食常与情绪相关。好心情是最佳「燃脂剂」——学会与焦虑和解，比盲目节食更重要。

懒人减肥武器库速览

维度 要点
饮食 能量赤字 + 营养充足；外卖少点高糖高油；麻辣烫不加麻酱也是多样饮食的好选择
运动 每天 10 分钟碎片化运动也有累积效应；选自己喜欢的项目才能坚持
情绪 识别压力性进食；用运动、社交替代零食快感
中医适宜技术 针灸、埋线、拔罐、穴位按摩等可作为辅助，需在专业医师指导下进行

瘦身密码（一）：中国式发福图鉴——14亿人的体重失控现场

近三十年，中国人以惊人速度「胖」了起来。据《中国居民营养与慢性病状况报告（2020）》，成年居民超重率 34.3%、肥胖率 16.4%——每 2 个成年人就有 1 人面临超重/肥胖威胁。

更令人警醒的是增速：1989 年中国超重人口约 1.67 亿，2009 年增至 5.29 亿，20 年间每天约增加 4.9 万人，年均增长率 10.8%，超过同期 GDP 增速。《柳叶刀》估算，2021 年全球超重/肥胖成年人 21.1 亿，中国以 4.02 亿居首；预计到 2050 年，全球将有超过一半成年人超重/肥胖。

若以腰围衡量腹型肥胖，2009 年中国腹型肥胖人口约 6.7 亿，超过欧美总和。李新华等团队在《柳叶刀》发表的研究显示，2004～2018 年间，18～69 岁人群标准化平均 BMI 从 22.7 升至 24.4 kg/m²，肥胖患病率（BMI≥30）从 3.1% 升至 8.1%。2018 年肥胖人数约 8500 万，是 2004 年的三倍。

谁更容易发胖？

肥胖增长并非均匀分布，城乡、性别、年龄各有特点：

维度 主要趋势
城乡 2010 年前城市高于农村；此后农村女性 BMI 增速快于城市，2018 年农村女性已超过城市
性别 2004 年男性低于女性，2018 年完全逆转，男性增速更快
年龄 女性随年龄升高至 50 岁；男性 30～49 岁为高峰
儿童 与 1985 年比，2014 年 7～18 岁学生肥胖患病率增长 54.8 倍
老年人 2011～2015 年超重率 29.2%→33.2%，中心性肥胖 58.3%→63.9%

肥胖正在吃掉你的存款

肥胖已从个人问题演变为国家危机。2024 年 6 月，国家卫生健康委联合 16 部门启动「体重管理年」活动，推动慢病防治关口前移。

健康代价：

  • 近 20 年高血压患病率 19%→28%，糖尿病约 3%→13%
  • 2018 年糖尿病及前期患病率合计约 51%，知晓率、治疗率、控制率均偏低
  • 预测 2030 年成人超重/肥胖率或达 70.5%

经济代价：

  • 2030 年归因于超重/肥胖的医疗费用预计约 4180 亿元，约占全国医疗费用 22%
  • 超重/肥胖对全球经济影响占 GDP 2.4%，2035 年预计升至更高
  • 肥胖还带来间接损失：工作效率下降、请假增多、就业机会受影响（「体型歧视」）

研究还发现，肥胖与收入的关系并非线性——中等收入人群肥胖风险反而最高；农村高收入男性、高教育男性肥胖关联更强，而女性高教育与肥胖呈负相关。

腰围比体重更值得警惕

BMI 虽常用，但有盲区：不区分肌肉与脂肪、不反映脂肪分布。腹型肥胖（苹果型）风险远高于梨型：

  • 男性腰围 ≥90 cm、女性 ≥85 cm，即存在腹型肥胖风险
  • 内脏脂肪升高甘油三酯、胆固醇，促动脉粥样硬化
  • 干扰胰岛素作用，显著增加 2 型糖尿病风险
  • 与结直肠癌、子宫内膜癌等多种癌症相关
  • 压迫横膈膜，引发睡眠呼吸暂停；加重关节负担

建议： 除定期测 BMI 外，务必关注腰围和腰臀比（亚洲男性上限 0.9，女性 0.8）。

写在最后

肥胖威胁的不只是外形，更是心血管、代谢、呼吸、骨骼乃至心理的全方位健康。2024 年「体重管理年」与「九体医学健康中国计划」的推进，标志着体重管理正从「一刀切节食」走向个体化、科学化、中西医协同的新阶段。

常见问题

Q: 必须用 Python 吗？
A: 不必。方式一只是改环境变量，任意终端/shell 均可；方式二需要 Node.js 来跑 ccr。

Q: DeepSeek 免费吗？
A: 注册会有一定免费额度，超出后按官方定价计费，详见 DeepSeek 定价页。

Q: 如何确认当前用的是 DeepSeek？
A: 方式一：看环境变量 ANTHROPIC_BASE_URL 是否为 https://api.deepseek.com/anthropic。方式二：在会话里输入 /status 查看当前模型。

Q: 长输出被截断或超时？
A: 增大 API_TIMEOUT_MS（例如 600000 表示 10 分钟）。
