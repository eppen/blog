北京 → 罗布泊无人区 → 红其拉甫 → 巴基斯坦 → 中东 → 北非 → 卡萨布兰卡

总图：北京 → 罗布泊 → 红其拉甫 → 中东 → 北非

图① 罗布泊段放大：吐鲁番 → 鄯善戈壁 → 龙城雅丹 → 楼兰 → 湖心 → 若羌；橙色虚线圈为风险段（R1）

罗布泊穿越段（陆路） 中东—北非段 途经点
R1 自然风险（戈壁 / 沙尘暴） R2 高人身风险（悬赏 / 爆炸） R3 极高人身风险（前线 / 路炸）
  1. 北京出发，西行经吐鲁番、鄯善戈壁，向南进入龙城雅丹
  2. 在楼兰古城一带穿行，抵达罗布泊湖心，再南出若羌（陷车、野骆驼、与沙尘暴赛跑都在这段）
  3. 沿塔里木盆地南缘西行，翻红其拉甫口岸（约 4700 m）进入巴基斯坦
  4. 经阿富汗、伊朗、伊拉克、叙利亚、土耳其，转北非，终到摩洛哥卡萨布兰卡

风险提示（对应图中 R1–R3）

  • R1罗布泊：反复陷车（靠绞盘、拖绳、另一辆车顶住防侧翻）；两股沙尘暴在前进路线上交汇，其中一股被称为"20 年不遇"，此后四小时在"陷车—拖拽—推车"中与沙暴赛跑；无人区内无信号、无补给。此前该区域已有彭加木（1980 失踪）、余纯顺（1996 遇难）。
  • R2阿富汗：2015 年 6 月在巴米扬用光影复原被炸毁的西大佛后，遭塔利班高额悬赏；正值"春季攻势"，针对外国人明码设赏；喀布尔爆炸、地雷与枪伤伤员不断。
  • R3伊拉克 / 叙利亚：巴格达一次爆炸袭击致 400 余人死亡，他们到现场参与收尸；沿线有路边炸弹，还去了库尔德与科巴尼前线。该季 2015 年 11 月曾因安全风险停播。

说明：罗布泊段（右上图）按节目行进顺序示意，节点坐标为真实经纬度，连线未按实际道路走向绘制；图中标注的是"湖盆/湖心"位置，罗布泊早已干涸，无水面。
风险圈（R1–R3）仅示意风险路段的性质与大致范围，不是实测边界，也不等于官方警戒区。
