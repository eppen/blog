MES 2026 年 8 月工作小结

8 月（截至 8/25，约 320 次提交、合并 PR #360 / #368–#381，另有多条功能分支直接合入）主线是把 mes-ai 从「能出表/图」推进到 配方化 SQL 查询、双区间对比与 AgentScope 子运行时，并同步加深看板下钻、工艺符号面板与 EOS 权限移除能力。改动最集中的模块是 mes-ai，其次 mes-chart / mes-web / mes-visual / mes-security；月末打上 release-2026-08-25。

一、MES-AI：sql_compose、双区间图与 AgentScope

  • sql_compose：配方化查询生成、别名/LIKE/单位校验、产耗默认负号、双区间对比图与 [区间1]/[区间2] 列标签；「回溯起算」日期解析与 TOP/CTE 安全注入。
  • AgentScope：新增 mes-agentscope 子模块，子 Agent 配置、权限模式、表格块与图表抽取、token usage 写入运行日志；管理端与协作编排联动。
  • 对话体验：Markdown/语法高亮、思考步骤、会话搜索与历史内嵌图表、运行日志反馈/复测、相对月份 SQL 参数、选项回答与工具移交编辑。
  • 能耗工具链：日表多装置、同比环比/趋势/饼图、存储过程工具出图、excludeFromUiTable、列组与汇总行、多日均值查询、当前时间预调用。

二、看板与可视化

  • 下钻：饼图/柱图弹层明细 → 行级二级详情；能耗模块明细 SQL 与多看板下钻文档补齐；多柱图支持。
  • 嵌套饼图：色相微调、固定品类配色、零值过滤与高亮；看板树展开、月份筛选与图表包导入导出。
  • 工艺工程：ISA 5.1 仪表符号面板、P&ID 工艺符号面板与生成脚本；设计图/图形资产页交互规范。
  • 项目甘特：可拖拽分栏、布局与基线/排程相关增强（mes-project）。

三、权限安全与其它业务

  • EOS：角色权限移除授权模式、孤立目录剪枝、菜单树拖拽重排、角色管理 UI 与菜单详情刷新交互。
  • 船舶 / 工作台：码头船舶待办 Provider；联锁强制投用率相关查询。
  • 计量：恒值监测状态持久化与告警联动、仪表型号管理、监测规则按电表批量查询。
  • 基础设施：Docker 本地直连端口映射、Flowable schema 自动升级；UI 查询区对齐与成功 msg/失败 alert 规范落地。

四、月度节奏

阶段 重点
上旬 协作子 Agent / 工具移交、相对月份参数、运行日志反馈复测、对话内图表合入（#360）
中旬 存储过程出图、能耗趋势/饼图/同比、嵌套饼与下钻、Eos 菜单拖拽与权限修复（#376–#381）
下旬 sql_compose 与双区间图、AgentScope、看板二级下钻、P&ID 符号面板、EOS 移除授权；发版 release-2026-08-25

一句话：8 月把 MES-AI 推到「能配方写 SQL、能双区间出图、能挂 AgentScope」，看板下钻与工艺符号面板同步成型，并在月末完成 release-2026-08-25 发版收口。
