MES 2026 年第 32 周工作小结

发表于2026-08-06|更新于2026-10-30|日志
|浏览量:

本周（8/3–8/6，约 50 次提交、合并 PR #360、#374）主线在 AI 图表内联渲染与相对月份推理修复，同时推进运行日志可观测性和 ExternalApi 集成。主力模块 mes-ai（167 文件触达），次为 mes-chart（15 文件）。

一、AI 图表内联与看板增强（#360）

在 AI 聊天中落地面向 SQL 工具的内联图表渲染，并增强看板筛选能力：

  • SqlToolChartPolicy：新增图表配置编辑入口，支持为 SQL 工具指定折线/柱状/表格等图表类型，查询结果直接在对话中渲染
  • 看板增强：Tab 筛选与可见性管理、月份过滤支持、renderFilterBar 异步时序修复
  • 健壮性修复：ClassCastException（图表配置为标量值时）、NumberUtil 统一替代自定义数值解析方法

二、相对月份查询修复（#985、#992）

针对性修复”上个月”等相对月份提示词输出错误日历月份的问题：

  • RelativeMonthOverviewNormalizer：正则从 RELATIVE_MONTH_PHRASES 集中化短语列表动态构建，消除分散常量
  • AgentReactExecutor：注入已解析年月提示，防止 Agent 在强制结单前过早输出 JSON 导致月份错误
  • 新增单测覆盖多种相对月份表述场景

三、AI 运行日志可观测性（#374）

  • 运行日志列表新增会话详情弹窗，支持按 sessionId 匹配 assistant 消息并展示
  • AiChatRunLogEntity 关联 SysUserEntity，日志列表展示用户信息（用户名/姓名）
  • AgentChatController 会话管理功能增强：分页、搜索、会话切换
  • AgentAnswerParser 新增 intentional_choices JSON 解析

四、ExternalApi 工具增强

  • URI 构造与编码重构，urlEncode 冗余方法移除
  • 测试用例覆盖 URI 特殊字符编码场景
  • 文档补充：高德天气工具、通用 External API 接入示例

五、文档与基础设施

  • MES vs Dify / AgentScope 对比文档大幅更新，详列成本/标注反馈闭环等维度差距
  • mes-ai 工具配置复杂度分析文档
  • 新增 mes-count-loc Skill
  • .mcp.json 加入 .gitignore，清理过期 LLM 文档和已吸收的单次 SQL 补丁

六、物料查询

  • 新增物料 ZZTJ 日进出 SQL 工具种子及文档索引
  • 物料单位 IO 明细查询增加含量、类别筛选参数

一句话：本周以 AI 图表内联和相对月份修复落地为主，运行日志可观测性明显提升，ExternalApi 和物料查询逐步补全。
