MES 2026 年第 35 周工作小结

发表于2026-08-31|更新于2026-10-30|日志
|浏览量:

本周（8/24–8/29，约 85 次提交，合并 PR #174、**#382** 等）主线在 壳层导航体验（全局搜索、侧栏、模块 Tab）、LIMS 数据源与位号对接、本地 bge-m3 embedding，以及工作台到期提醒与 EOS 权限移除。主力模块 mes-web / mes-visual / mes-factory / mes-ai。

一、壳层导航与全局搜索（#174）

  • 全局菜单搜索：组件布局、响应式样式与状态管理；z-index 与下拉交互
  • 侧栏：折叠态展示、滚动行为、本地过滤；菜单加载后再初始化路由
  • 模块 Tab / 导航栏：Tab 布局与样式、打开方式项；页脚版权年份动态化
  • 角色详情页布局可读性调整

二、LIMS 数据源与位号

  • LIMS 数据源配置：RDB SQL 数据源实现；精度保留；sys_config value 扩至 4000
  • 结果数据：筛选排序、网格配置与菜单 SQL
  • 位号（fm）：导入下载对接 LIMS；采集流程与样式收敛
  • 数据源配置页 JSON 编辑器

三、AI embedding 与知识库

  • 默认改用本地 bge-m3 embedding（免 API Key）；Docker 环境配置同步
  • 知识库 测试检索 能力与 UI
  • 当前时间预调用（系统消息前置合并）；SQL 工具参数解析增强

四、工作台、到期提醒与容器

  • 首页 badge 接口与工作台快照/超时处理
  • 到期提醒：状态判定、聚合调度、复制；工作台提醒汇总
  • 容器工作台 providers 与状态计数；任务组参数加载
  • 首页提示统一为 msg / alert

五、工艺可视化、过程控制与安全

  • P&ID：集成 draw.io Stencils、ISA 符号管理；SVG 描边与样式归一
  • 过程控制（#382）：超限异常记录时长计算与写入
  • EOS 权限：角色权限「移除授权」模式；清理孤立空目录
  • Docker 本地直连端口映射、Flowable schema 自动升级等开发便利项

一句话：本周以壳层导航与全局搜索落地为主，LIMS 数据源/位号与本地 embedding 并进，工作台到期提醒与 P&ID 图元、EOS 权限移除补齐平台与安全侧能力。
