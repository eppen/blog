Cursor Agent CLI 报错 No version directories found 的排查与修复

发表于2026-06-19|更新于2026-10-30|技术
|浏览量:

在 Windows 终端执行 agent 或 cursor-agent 时，可能遇到如下错误：

本文记录该问题的现象、根因、修复方式与临时绕过方法。

现象

  • agent、cursor-agent 命令均无法启动
  • 报错提示在 %LOCALAPPDATA%\cursor-agent 下找不到版本目录
  • 但手动查看 versions 子目录，实际存在多个版本文件夹，例如：

根因

agent.ps1 与 cursor-agent.ps1 启动时会扫描 versions 目录，并用正则过滤合法版本名：

该正则只匹配旧格式：

例如：2026.06.16-a07d3ac

而 Cursor Agent 更新后的目录名变为新格式，中间多了构建时间：

例如：2026.06.16-20-30-07-a07d3ac

因此所有现有版本目录都被过滤掉，脚本误判为「没有版本目录」。

修复方法

编辑以下两个文件（内容相同，需同步修改）：

  • %LOCALAPPDATA%\cursor-agent\agent.ps1
  • %LOCALAPPDATA%\cursor-agent\cursor-agent.ps1

修复前会自动备份为 agent.ps1.bak-YYYYMMDD-HHMMSS，并尝试执行 agent --version 验证。

注意事项

  1. 更新可能覆盖修复：执行 agent update 或 Cursor 自动更新 Agent CLI 后，agent.ps1 可能被还原，问题会复现，需重新应用上述修改。
  2. IDE CLI 与 Agent CLI 是两套工具：
    • cursor：Cursor IDE 自带 CLI（打开文件、diff、tunnel 等），路径通常在 %LOCALAPPDATA%\Programs\cursor\resources\app\bin\
    • agent / cursor-agent：终端 Agent CLI，安装在 %LOCALAPPDATA%\cursor-agent\
  3. cursor agent 子命令：IDE CLI 也注册了 agent 子命令，但日常使用的 agent 命令通常来自 PATH 中的 cursor-agent 包装脚本。

相关环境信息（排查参考）

项目 值
Cursor IDE 版本 3.8.11
Agent CLI 版本 2026.06.16-20-30-07-a07d3ac
操作系统 Windows 10/11 x64
安装路径 %LOCALAPPDATA%\cursor-agent\

总结

No version directories found 并非版本文件缺失，而是 PowerShell 启动脚本的版本名正则未跟上 Cursor Agent 新的目录命名规范。更新正则后即可恢复正常；若再次被更新覆盖，按本文步骤重新修复即可。
