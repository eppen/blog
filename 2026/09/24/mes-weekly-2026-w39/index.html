MES 2026 年第 39 周工作小结

发表于2026-09-24|更新于2026-10-30|日志
|浏览量:

本周（9/21–9/24，约 47 次提交、22 次合入）主线是 计量器具 Excel 模板链路（.xlsm / VLOOKUP / zip 一键准备），辅以 TSDB 连接稳定性 与 报表调度体验。合入分支主要包括：spike/msr-template-xlsm-datepicker、feature/msr-template-unit-lookup、feature/msr-template-depart-unit-filter、feature/msr-xlsm-vba-sign、feat/tsdb-client-pool、feat/tsdb-rt-hd-split-lock、feat/rpt-report-schedule、feat/menu-eos-refresh-vessel-monthly。主力模块 mes-measure、mes-rtdb、mes-core / mes-chart。

一、计量器具模板（mes-measure）

  • 支持 .xlsm 导入与模板下载；日期控件 spike、VBA 签名相关合入
  • 模板增强：VLOOKUP 装置查找；运行部下载预填部门，并按管理部门筛装置
  • 导入改为 zip 包 + 本机一键准备；出厂日期展示与日期转换（/、.、Excel 数值日期）修复
  • 修公式缓存显示 0、空装置编号默认 0；按选项加宽装置名称列
  • 重新生成计量器具操作手册 docx

二、实时库与监控（mes-rtdb / mes-chart）

  • TSDB 实时 / 历史 client 分锁，并改为 固定连接池
  • ISYS SDK 监控页挂到平台菜单
  • 数据库监控看板：阻塞数报警，并可跳转解锁页

三、报表调度（mes-quartz / mes-report）

  • 报表调度筛选、任务卡片布局与样式
  • 展示上次执行结果、下次执行时间；状态展示更清晰

四、菜单、装置选择与其它

  • 菜单：EOS 菜单 URL 刷新；容器月度运行数据查询与 widget
  • 装置选择页展示 URL 传入的管理部门条件
  • Maven Surefire 插件配置，便于测试执行

节奏

时段 侧重
周一 报表调度 UI / 任务卡片
周二 Excel 日期转换、.xlsm 导入、菜单同步
周三～周四 msr 模板 VLOOKUP / 部门筛选 / zip 包；TSDB 分锁与连接池

一句话：模板从「能下能导」推进到「带宏、可查找、可打包准备」；实时库侧把并发访问收成固定池与分锁，调度页则把执行信息补齐到卡片上。
