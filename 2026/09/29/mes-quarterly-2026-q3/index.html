MES 2026 年三季度工作小结

2026 年三季度（7–9 月，约 1108 次提交：7 月 402 / 8 月 428 / 9 月 278）合并 PR 约 #312–#385（约 61 个）。主线是把 mes-ai 从「能问」推进到「能查、能画、可观测、可回滚」，并同步加深看板能力、计量导入闭环，以及多应用拆分与实时库底座。触达最多模块：mes-ai ≫ mes-chart / mes-web / mes-measure / mes-core；另有 mes-security、mes-report、mes-rtdb、mes-visual 等持续迭代。

一、MES-AI：工具链、多 Agent 与可观测

  • 多 Agent / 路由：多 Agent 入口、协作子 Agent 并行与隔离上下文、工具互斥与示例增强、Planner 多专业、工具移交编辑（#352、#368、#369 等）。
  • SQL / 存储过程工具链：参数槽位、存储过程工具、相对月份参数、excludeFromUiTable、双周期对比图、sql_compose 配方化拼装（#344、#356、#357、#365、#371）。
  • 对话体验：停止生成、内联图表、Markdown 展示、表格列组/着色/合计行、答案选择、会话历史（#326、#360、#377、#358–#361）。
  • 可观测与治理：运行轨迹、重试/复测反馈、LLM API 用量记录、Agent/Tool 配置快照备份回滚、本地 LLM profile（#328、#333、#374、#314）。
  • 业务场景：生产运行 FC、能耗日查询/饼图趋势、联锁投用率、装置开停工区间、工程师日志录入（#324、#363、#381、#366）。
  • AgentScope：8 月引入子运行时，子 Agent 配置、权限模式与协作编排联动。

二、看板与图表（mes-chart）

  • 能力增强合入 #384：书签 URL、筛选联动、透视、虚拟滚动、看板导出、数字卡下钻、SQL 安全校验（Druid）等。
  • 能耗与下钻：饼图/趋势/同比、图表下钻到明细、嵌套饼色相与零值过滤。
  • 演示与运维：DEMO 组织看板 KPI 与末级部门人数表、数据库监控阻塞数报警并跳转解锁页。
  • 工艺可视化：ISA / P&ID 符号面板与相关资产页交互。

三、业务模块：计量、报表、船舶与计划

  • 计量器具（msr）：菜单/字典种子、xlsm 模板与 VBA、部门/装置筛选、导入 zip 与本机一键准备、VLOOKUP 装置查找。
  • 报表：模板历史/回滚/检查点、AI 公式检查（#385）、报表调度与 Quartz 联动（任务卡、上次结果/下次执行）。
  • 船舶 / 罐区 / 计划：月度运行 widget、黑名单导入导出、罐日与库存平衡 UI 优化、计划范围导入摘要与未匹配装置提示。
  • 工作台：P0–P2、到期提醒工作台（#327、#383）。

四、平台、权限与基础设施

  • EOS 权限与菜单：角色对象权限、批量删权、菜单 v2（拖拽排序、按 app 检索、刷新 EOS URL / hash）。
  • 多应用拆分：平台抽出，mes-web / 报表 / 调度独立子应用（feat/mes-app），依赖与文档同步整理。
  • 安全与通用：JSON 请求加密、用户导出、jqGrid 全局错误处理、在线消息详情。
  • 调度与实时库：Quartz P0–P2 工程化；TSDB / ISYS SDK 接入、实时/历史 client 池与分锁、监控页挂菜单。
  • 其它：LIMS 数据源配置、EOS 文档数据、可视化工艺面板等。

五、季度节奏

月份 重点
7 月 AI 工具链与多 Agent 底座、Quartz 工程化、工作台 P0–P2、EOS 权限与工程师日志
8 月 对话内联图 / 能耗图、sql_compose 与双区间、AgentScope、看板下钻、计量与到期提醒；发版 release-2026-08-25
9 月 看板能力合入（#384）、报表公式检查（#385）、计量 xlsm、多应用 / 菜单 v2、TSDB、报表调度

一句话：三季度把 MES-AI 做成可查询、可出图、可追踪与可回滚的生产能力，看板与计量导入闭环同步成型，并启动多应用拆分与实时库底座，为后续独立部署与时序数据接入铺路。
