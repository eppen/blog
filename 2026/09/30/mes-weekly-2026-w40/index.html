MES 2026 年第 40 周工作小结

发表于2026-09-30|更新于2026-10-30|日志
|浏览量:

本周（9/28–9/30，约 17 次提交）主线是 多应用拆分落地 与 RTDB / ISYS SDK，并修正 LIMS 位号、EOS 菜单 URL。合入分支主要包括：wip/tsdb-sdk-decompiled、feature/lims-tag-optional-sample-name、feat/mes-app。主力模块 mes-web、mes-factory、mes-rtdb、mes-security、mes-report。

一、实时库 / ISYS SDK（mes-rtdb）

  • 合入 wip/tsdb-sdk-decompiled，沉淀 TSDB SDK 反编译参考
  • 新增 ISYS SDK 接入：独立端口与上下文、Nginx 代理、监控相关配置与文档
  • 完善 ISYS SDK 与多应用说明文档

二、多应用拆分与基础设施（mes-web / scripts）

  • 应用拆分后 日志文件按应用拆分；补充 mes-utils / mes-chart / mes-message-eos 等依赖
  • Nginx 兼容历史 PDF 路径；清理部分测试子工程
  • 整理 scripts/build-all 目录处理与错误管理

三、LIMS 位号（mes-factory）

  • 样品名可空：导入 DTO、位号生成与取数逻辑同步调整，并更新说明与单测
  • 合入 feature/lims-tag-optional-sample-name

四、EOS 菜单与安全（mes-security）

  • EOS 菜单 URL 刷新：仅改写 .html，跳过 jt-web hash 路由
  • 补充 EosMenuTypeHelper 与相关单测

五、文档

  • 报表定时操作手册（md / docx + 截图）
  • 新增《JSON 请求体传输加密说明》

节奏

时段 侧重
周一 ISYS SDK / TSDB 反编译参考合入；LIMS 样品名可空
周二 EOS 菜单 URL；多应用依赖与日志拆分；nginx PDF；报表手册
周三 build-all 脚本整理；传输加密说明文档

一句话：把多应用拆分从依赖与日志侧再推进一步，同时把 ISYS SDK 与 LIMS/菜单边界问题收干净。
