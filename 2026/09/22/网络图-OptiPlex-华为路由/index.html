OptiPlex + 华为路由 网络图

发表于2026-09-22|更新于2026-10-30|技术
|浏览量:

用途：本机作为局域网 DNS 过滤机（AdGuard Home），拦截网络内游戏等域名访问。

设备一览

设备 角色 地址 / 端口
华为路由器 HUAWEI-EX1XZ2 网关 / DHCP 192.168.3.1
Dell OptiPlex 7040 DNS 过滤机 固定 IP 192.168.3.7（WiFi wlp3s0）
AdGuard Home DNS / 管理界面 DNS :53，管理 http://192.168.3.7:3000
手机 / PC / 游戏设备 客户端 192.168.3.x（DHCP）

网段：192.168.3.0/24

sequenceDiagram

  Note over R: DHCP 把 DNS 下发为 192.168.3.7

    U-->>A: 返回真实 IP

    R->>U: 转发上网
  end

要点说明

  1. AdGuard 只拦 DNS：域名解析在 OptiPlex 上过滤；实际网页/游戏数据包仍经华为路由上网。
  2. 全网生效前提：路由器 DHCP 的 DNS 服务器填 192.168.3.7，客户端重连 WiFi 后生效。
  3. 本机固定 IP：OptiPlex 已设为 192.168.3.7/24，网关 192.168.3.1。建议在路由里做 DHCP 地址保留，避免冲突。
  4. 53 端口：已关闭 systemd-resolved 的 DNSStubListener，由 AdGuard 监听 *:53。
  5. 绕过可能：客户端改用公共 DNS、DoH/DoT、代理、直连 IP 时，DNS 黑名单可能失效。
