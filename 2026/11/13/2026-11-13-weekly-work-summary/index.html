本周工作小结（2026-11-07 ~ 2026-11-13）

发表于2026-11-13|更新于2026-11-21|工作小结
|浏览量:

本周 jt-mes 项目共提交 72 个 commit，主要围绕三条线推进：EOS 单据设计器、固体盘点、SSO 单点登录。

1. EOS 单据设计器

单据设计工具持续增强，本周合入 feature/eos-document-design 分支：

  • 表头设计器支持框选多选、整体移动与对齐/分布
  • AI 排版支持参考同类老单据，默认排版按现场实测校准
  • 预览、DjType 推断、label 样式与 DDL 优化
  • 右键菜单与工具栏图标统一为 FA4.7 可用图标
  • nwf 设计器支持节点跨页面/跨流程复制粘贴、传递线折点可视化编辑与直角订正

2. 固体盘点

  • 人工确认值改为列表内联录入并批量保存，当前页未提交行均可编辑，无需勾选
  • 生成盘点数据时默认同步生成人工确认值，统一保留三位小数
  • 修复保存失败（confirmEdited 改用 @JsonProperty(WRITE_ONLY)）、清空保存为 0 等问题
  • 导出明细列对齐遵守项目规范（数字右对齐/文字左对齐/标题居中）
  • 填报单位改从 sys_user.categories 取末级部门（PartyH 已废弃）
  • 补充端到端测试文档与截图

3. SSO 单点登录

  • 接入 CAS 单点登录，完善 Docker/Nginx 部署配置
  • EOS token 绑定支持 CheckToken 校验与过期换发，前端在 urlToken 场景强制走后端交换

4. 其他

  • 计量监控（msr）：静态资源迁回 mes-measure-monitor 模块；报警统计 SQL 抽取 SqlDialect，支持 MySQL/SQL Server 方言自动适配；补 SQL Server 集成测试与全量菜单 SQL
  • 在线操作手册：sys 11 篇、mes-quartz 6 篇、mes-operation 6 篇，业务页面统一加「使用说明」帮助按钮
  • 平台：quartz 平台页聚合各应用调度任务；窄屏下折叠全局菜单搜索为图标
  • 基础设施：nginx 开启 gzip 与 utf-8 charset；.dockerignore 放行 platform/report/dispatching 的 jar；新增结构漂移体检脚本
  • 修复：xls 导出重建 inlineStr 单元格（修复 WPS/新版 Excel 模板占位符替换失效）、AI 会话 userId 非空校验、sys-schedule 切换 bean/方法同步刷新任务参数区等

下周计划

  • EOS 单据设计器继续迭代
