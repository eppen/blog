《侣行》第三季到底走的哪条线？我把张昕宇、梁红那段路画成了一张图

发表于2026-11-19|更新于2026-11-21|生活
|浏览量:

先回答问题：是罗布泊

被问到「他们横穿的是罗布泊吗」，答案很简单：是。动手查了一下这两人的资料，才发现值得单独记一笔——第三季那段路，前半段是自然风险，后半段是人身风险，两种危险性质完全不同。

先把路线摆清楚：

北京 → 吐鲁番 → 鄯善戈壁 → 龙城雅丹 → 楼兰古城 → 罗布泊湖心（自北向南穿无人区）→ 若羌 → 红其拉甫口岸 → 巴基斯坦 → 阿富汗 → 伊朗 → 伊拉克 → 叙利亚 → 土耳其 → 埃及 → 利比亚 → 突尼斯 → 阿尔及利亚 → 摩洛哥·卡萨布兰卡

也就是说，罗布泊只是开场的第一段，从若羌出来、翻过红其拉甫，才是这季真正的主体：一路向西穿过中东 16 国，终点卡萨布兰卡。

罗布泊段：难，但可控

这一段是自然风险，也是最容易被短视频剪成「生死穿越」的部分。实际遇到的麻烦很具体：

  • 反复陷车：「太白」进沙漠后陷沙多次，靠绞盘、拖绳拉出来；在雪窝、斜坡上也陷过，甚至要另一辆车顶住防侧翻。
  • 和沙尘暴赛跑：后方气象支援预警有两股沙暴第二天会在他们的前进路线上交汇，其中一股被形容为「20 年不遇」。张昕宇选择迎风前进，结果车在斜坡深陷，半小时内沙暴中心就到，最后是梁红开「大白」拖、全员下车推拉填，之后四个小时一直是「陷车—绞盘—牵引—前进」的循环，直到错开路线。
  • 无人区常态：没信号、没补给，路上偶遇野骆驼。

需要说清楚的是风险等级：罗布泊确实出过人命——1980 年彭加木在库木库都克一带失踪，至今未找到；1996 年余纯顺在罗布泊徒步遇难。但那两位是单人徒步、缺少后援。张昕宇、梁红是两辆改装 G500、车队编组、卫星通讯加远程气象支持，「陷车—脱困」对他们是要花几小时的重体力活，不是致命事件。这两件事不该混为一谈。

中东段：这才是真会死人的地方

从红其拉甫出去之后，危险换了性质——不是自然给的，是人给的：

  • 塔利班悬赏：2015 年 6 月他们在巴米扬用光影技术 1:1 复原了被炸毁的西大佛，引起塔利班愤怒，高价悬赏他们的性命。
  • 正赶上「春季攻势」：塔利班专门针对外国人下手，按国籍明码标价。
  • 爆炸现场：巴格达一次恐袭后，他们跟着去收尸。
  • 地雷与路边炸弹：喀布尔急救医院里大量伤员来自枪击、地雷、路边炸弹。
  • 因安全风险停播：这一季 2015 年 11 月曾因安全风险中断播出，2016 年 8 月才恢复播完。

他们自己的应对是雇武装安保、走部队级火力配置，加上每次出发都留遗嘱（纸质和视频各一份）。这句话本身比任何形容词都能说明风险量级。

所以图上我把风险分了三级：

标记 区域 风险性质
R1 罗布泊无人区 自然风险：陷车、沙尘暴、无信号无补给
R2 喀布尔 / 巴米扬 高人身风险：针对外国人的袭击与悬赏
R3 伊拉克—叙利亚一线 极高人身风险：恐袭、路边炸弹、前线

关于这张图的几点说明

  • 城市节点用的是真实经纬度；国界底图来自 Natural Earth 1:110m，公开数据。
  • 连线是示意，不是实际行车轨迹；中东段的具体走法我没能逐一核实，只能按公开报道的城市顺序连起来。
  • 风险圈的范围是示意，不是实测边界，只为表达「哪几段危险、危险的性质有什么不同」。
  • 图是用一个 Node 脚本（读 GeoJSON → 墨卡托投影 → 输出 SVG）生成的，可复现；地图本身是纯静态 HTML，没有任何外部依赖，所以能整页塞进 iframe 里。

一句题外话

查资料时还看到一件容易混淆的事：他们 2017 年环球飞行用的那架运-12「超级白」，历史上曾完成首次穿越罗布泊和塔克拉玛干——但那是飞机的前任经历，不是他俩的。看纪录片和看二手转述，差别往往就在这种地方。

如果后面有人问「他们横穿的是罗布泊吗」，现在可以直接把这张图甩过去。
