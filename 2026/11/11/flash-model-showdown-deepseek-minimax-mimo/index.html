Flash 三国杀：DeepSeek / MiniMax / 小米 MiMo 轻量旗舰对比

发表于2026-11-11|更新于2026-11-14|技术
|浏览量:

2026 年底，三家国产厂商几乎同时把「Flash」档推到台前：DeepSeek 的 V4.1-Flash、MiniMax 的 M3.1 Flash、小米的 MiMo-V2.6-Flash。它们都主打「快 + 便宜」，但定位并不重合——一个押注极致成本，一个押注 Agent 能力，一个押注多模态。本文把三家的官方规格、benchmark、价格和速度摆在一起，帮你按场景选。

一句话定位

模型 一句话定位
DeepSeek V4.1-Flash 极致成本 + 高并发，缓存命中近乎免费
MiniMax M3.1 Flash Agent / 编程 / 电脑操作，速度最快
小米 MiMo-V2.6-Flash 多模态（含音频），输出价最低

规格对比

维度 DeepSeek V4.1-Flash MiniMax M3.1 Flash MiMo-V2.6-Flash
上下文窗口 256K 200K 256K
最大输出 384K 128K 128K
思考模式 可开关 常开（不可关） 可开关
多模态输入 文本 文本 文本 + 图像 + 音频
并发上限 2500 未公开 未公开

几点值得注意：

  • DeepSeek 的输出上限 384K 是三者中最长，适合超长生成任务；并发 2500 也是公开数据里最高的，适合高并发批量场景。
  • MiniMax 的思考模式常开、不可关闭，意味着每一轮都会产生思考 token，成本和延迟都吃这一点；换来的是推理能力的稳定发挥。
  • 只有 MiMo 支持音频输入，是三者里唯一能做语音相关任务的原生多模态模型。

Benchmark 对比

这里必须先说明一个数据缺口：只有 MiniMax 公开了 Flash 档的完整 benchmark，DeepSeek 和小米对 Flash 档都只给了规格、没给详细分数（DeepSeek 的详表只覆盖 Pro / R1，小米只宣传了 Pro 的 Artificial Analysis 46.32 分）。所以下面的对比对 MiniMax 是「实测」，对另两家是「未披露」。

MiniMax M3.1 Flash 官方公布的成绩：

Benchmark M3.1 Flash
DeepSWE（编程） 73.7%
Terminal-Bench Pro 51.6%
BrowseComp 50.0%
AgentCompany 76.0%
OSWorld（电脑操作） 61.7
CyberGym 82.0%
Vending-Bench 2 2393

从这份表能看出 MiniMax 的重心非常明确：Agent、编程、电脑操作、网络安全这几类任务全面领先，尤其 OSWorld 61.7 和 CyberGym 82% 在 Flash 档里是稀缺的。代价是它没有把「通用对话 / 写作」作为宣传重点。

DeepSeek 和 MiMo 的 Flash 档没有对应分数可比，这是官方未披露，不是本文遗漏。若要横向比编程或 Agent 能力，目前只能参考它们 Pro 档的成绩，但那已经不是「Flash 对 Flash」的公平对比了。

价格与速度

以官方 API 定价为准，单位为每百万 token（¥ / $）：

项目 DeepSeek V4.1-Flash MiniMax M3.1 Flash MiMo-V2.6-Flash
输入（缓存未命中） $0.034 ¥1.5（≈$0.21） ¥1.2（≈$0.17）
输入（缓存命中） $0.003 未公开 未公开
输出 $0.12 ¥4（≈$0.56） ¥2（≈$0.28）
速度 未公开 200+ TPS 未公开

价格上有几个反差点：

  • DeepSeek 的缓存命中价 $0.003/M 几乎等于免费，对重复前缀多的场景（如长 system prompt、RAG、多轮对话）成本优势碾压级。
  • MiMo 的输出价 ¥2/M 是三者最低，输出密集型任务（长文生成、代码补全）更划算。
  • MiniMax 输出价 ¥4/M 最贵，叠加「思考常开」带来的额外思考 token，实际单次成本会明显高于标价。
  • 速度上只有 MiniMax 公开了 200+ TPS，是三者里唯一有明确速度数据的，对延迟敏感的交互式 Agent 场景是加分项。

怎么选

按场景给结论：

  • Agent / 编程 / 电脑操作 / 网络安全 → MiniMax M3.1 Flash。它是唯一有完整公开成绩且在 DeepSWE、OSWorld、CyberGym 上领先的，200+ TPS 也最快。代价是思考不可关、输出价最贵，预算敏感时要掂量。
  • 多模态（尤其音频 / 视频） → MiMo-V2.6-Flash。唯一原生音频输入，输出价最低，适合语音交互、音视频理解类应用。
  • 极致成本 / 高并发批量 → DeepSeek V4.1-Flash。缓存命中 $0.003/M 近乎免费，输出上限 384K 最长，并发 2500 最高，适合大批量、重复前缀多的离线或半离线任务。

如果只能记一句话：要 Agent 能力选 MiniMax，要多模态选 MiMo，要省钱选 DeepSeek。

数据来源

  • DeepSeek：官方定价与模型文档（V4.1-Flash 规格、价格、并发；benchmark 详表仅覆盖 Pro / R1）。
  • MiniMax：官方博客《MiniMax M3.1 Flash：为 Agent 而生的轻量旗舰》（规格、benchmark、价格、200+ TPS）。
  • 小米 MiMo：官方文档（MiMo-V2.6-Flash 规格、价格、多模态能力；Pro 档 Artificial Analysis 46.32 分）。

说明：三家对 Flash 档的信息披露程度不同，MiniMax 最完整，DeepSeek 与小米未公布 Flash 档详细 benchmark。本文所有数据均来自各厂商官方渠道，未混入第三方评测。
