MES 2026 年 11 月工作小结

发表于2026-11-27|更新于2026-11-27|日志
|浏览量:

11 月（11/01–11/27，月中统计）共 189 条提交、21 次分支合并，触达 888 个文件、**+90,539 / −24,175** 行。这个月的主线是把 EOS 从「能调用的工具」做成「可交付的平台」：单据格式设计器与流程图设计器各自成型，调度指令审批整体迁到 EOS NWF，审批体系独立成模块并补上真流程图展示；同时新建 生产核算（PA）模块，仓库盘点与计量监控两条业务线收尾，最后几天集中做 EOS 用户管理与密码口径闭环。

一、EOS 单据设计器：从「能改」到「能设计」

10 月做的是流程定义维护，11 月把单据这一侧补齐——不必再回 EOS 客户端画单据。

  • 定义层互导：单据定义支持与 EosBuilder 双向导入导出；导出带入选中单据、补齐空分区与空单据头；选择拷贝目标目录的弹层加展开全部 / 收起全部
  • 格式设计器（新建）：画布排版 + 表体列 + 装饰对象，配 mxGraph 风格的拖动对齐辅助线；拖拽交互与 iframe 相对路径解析一并修掉
  • AI 排版：单页自动布局；可参考同类老单据作为样板，默认排版按现场实测结果校准
  • 表头设计器：框选多选、整体移动、对齐与分布，让批量调格式不再逐个拖
  • 设计工具增强：预览、DjType 推断、label 样式与 DDL 优化
  • 安装向导（eos-nwf）：支持配置 Redis 连接参数、只读账号模式（跳过建表 / 种子脚本，页面展示待手工执行 SQL）、密钥写入 setup-key.txt 并自动执行 mes-nwf 建表脚本；切库后保留 dbo. 两段式，避免 CREATE FUNCTION 失败

二、EOS NWF：流程设计器从「画得出来」到「改得动」

mes-workflow/mes-nwf（85 文件）这个月的主线是拓扑编辑：

  • 折点编辑：折点可视化编辑、传递线折点编辑与直角订正
  • 复制粘贴：节点支持跨页面 / 跨流程复制粘贴（先 Ctrl+C/V，后扩到跨流程）；修掉删除节点 / 改连 / 断开 / 新建传递线在确认后不生效的缺陷
  • AI 增量改图：定义增量改图协议，设计器识别拓扑变更并清理陈旧诊断信息
  • 导入策略：流程导入支持「新建 / 覆盖」两种模式，避免误覆盖现场在跑的流程
  • 运行时页面：新增我的待办 / 我的已办 / 流程实例监控三个只读页，补齐模块可用性

三、调度指令接入 EOS 审批（11/16 起的月度焦点）

  • 单据拆分：事业部指令与计划调度部指令拆成两个 EOS 单据，MES 实体回退旧三表，避免为迁就新流程改动业务表结构
  • 审批人表达式：runsql + uf_get_wf_spyh 两级取人落地，审批人不再写死在流程里
  • 撤回与同步：补撤回功能、待审批页可撤回、审批入口免写死地址；撤回时先同步审批状态，避免把已结束流程误报为「正在处理」；待办列表与详情页增加手动同步 EOS 审批状态
  • 列表口径：待审批 / 已完成默认按 ID 倒序（修新数据被挤到末页）、状态下拉补「提交中」并让筛选真正生效
  • 单据拷贝：dd / bu 指令单支持拷贝——带入业务字段与附件生成新草稿，不沿用 djGuid 与审批状态
  • 配套：编制部门写入补齐、DD 编制部门回填脚本修正、EOS 任务注册与实体视图可更新修复脚本

四、审批体系：独立模块 + 真流程图

  • **新模块 mes-workflow-approval**：审批组独立出来，编码唯一键改为「部门 + 编码」；成员改按审批组 ID 关联，新增批量新增审批组；查询下拉按编码去重排序，避免跨部门重复项
  • 审批进度：弹窗改为 SVG 真流程图，新增「审批进度 / 流程图」双页签，并加流程定义节点步骤条；另提供独立的 EOS 审批进度组件
  • 规范对齐：审批组用户配置三栏改 flex、新增 approval-group.css、jqGrid 分页统一 rowNum 30 + rowList 10/20/30/50/100 并同步 HTML 引用版本
  • 平台侧：角色 / 用户分组树同层按拼音排序且未分组置顶；部门选择弹窗显示上级部门

五、新建生产核算模块（mes-production-accounting）

对标 PAR 一次性铺四个阶段，mes-mass-balance 标记弃用：

  1. 骨架：模型 / 节点 / 路由 / 期间 / 记录 CRUD，SdrSolver 校正算法，pa 页面与菜单 SQL
  2. 数据质量：精度解析、GLR 粗差检验、缺失推断、限值违规，前端页面迁入本模块
  3. 平衡计算：多量纲同步平衡、储罐池、CALC 公式取数、罐计算按量纲
  4. 可追溯：模型改动审计留痕、historian 回写、审计导出、核算报表

六、仓库盘点与计量监控

固体仓库盘点这个月把「人工确认值」做成了完整闭环：生成数据时默认同步生成、列表内联录入并批量保存、录入无需勾选（当前页未提交行均可编辑）、统一保留三位小数、清空按 0 保存。期间修掉两个真问题：confirmEdited 用 @JsonProperty(WRITE_ONLY) 解决保存失败；round3 对空值原样返回空串导致清空变 0。导出侧套用盘库表模板、明细列按「数字右对齐 / 文字左对齐 / 标题居中」对齐规范、填报单位改从 sys_user.categories 取末级部门（PartyH 已废弃）；确认人 / 盘库人 / 审核人关联 sys_user 显示真实姓名，盘库人改弹框选择并移除监盘人字段。

顺带修了 Excel 导出的底层坑：导出时重建 inlineStr 单元格，解决 WPS / 新版 Excel 上模板占位符替换失效。

计量监控（msr）：报警统计 SQL 抽出 SqlDialect 支持 MySQL / SQL Server 方言自动适配；修报警确认在非 Web 场景下保存失败、仪表台账首屏报错且默认不带模型编码请求；静态资源从 mes-web 迁回 mes-measure-monitor 模块；补 SQL Server 集成测试与全量菜单 SQL。

七、EOS 用户管理与密码口径

11/23 起集中打通 EOS 与 MES 两侧账号（mes-security-eos、stusers）：

  • 列表与详情：只读列表页（查询 + 带进度条导出）、详情页聚合 EOS / MES 权限信息、用户分组树、菜单 SQL 补齐按钮权限
  • 写操作：新增 / 编辑 / 重置密码、拷贝用户与拷贝权限（按钮权限拆分）、角色授权与工作组授权双栏弹层（角色映射同步、工作组全量替换 MESQXB 关联）
  • 删除与状态：批量选择删除、级联删除同名 MES 账号（角色 / 工作组 / 账号）、启用禁用同步 MES 账号状态
  • 密码口径：统一 resolveDefaultPassword，未配置即告警；加密改为 seed:password 约定，DPSeed 为空时生成 8 位种子；拷贝用户密码按 EOS 明文口径落库；补密码加密与校验单测

细节详见本周的周报，月报不再展开。

八、平台基座与工程化

  • 安全：接入 CAS 单点登录 并完善 Docker / Nginx 配置；EOS token 与 MES 交换 token 生命周期对齐；补附件权限脚本
  • 依赖：POI 4.1.2 → 5.2.5（配套适配）；新增 mes-formula 模块；spring-ai 1.0.0-M6 的 OpenAiAutoConfiguration 在 Boot 2.7 下会抛 TypeNotPresentException，排除该自动配置（项目实际用自研 LlmChatClient）
  • 配置：各子应用与 nginx 文件上传上限统一 500MB；spring-boot-maven-plugin 跳过父 POM 执行、规避 JDK 8 命令行长度限制
  • 架构：平台页聚合各应用调度任务；窄屏下全局菜单搜索折叠为图标；areaselect 区域选择页从 mes-web 移到 mes-factory 并修双击选行
  • 稳定性：日志切面主键转换容错（修附件删除 NumberFormatException）、附件删除接口支持字符串数组主键、修附件 ATT_NUM 不回写、用户列表创建时间排序改 JPA 属性名
  • 业务细节：交接班 Word 导出按班次计算起止时段、上下边距 112dxa、补齐班次时间占位符；报表定时增加下载模板；日志管理新增跨应用错误汇总 errorSummary；补录 M_BZ_DZ 模型注册并修班组统计装置下拉与锅炉小指标归属；mes-utils 新增实时数据库存储容量估算

九、在线操作手册

12 条 docs 提交，补 151 篇在线操作说明（sys 16、warehouse 13、energy 12、monitor 11、dispatching 10、workflow 8、document 8 …），其中 Jt-Web 49 个页面单独成批；业务页面统一加「使用说明」帮助按钮，扫码即看，减少了现场问「这个字段填什么」。
