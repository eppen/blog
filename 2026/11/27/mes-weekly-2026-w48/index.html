MES 本周工作小结（2026-11-23 ~ 11-27）

发表于2026-11-27|更新于2026-11-27|日志
|浏览量:

本周（11/23–11/27）以 EOS 用户管理体系闭环 与 派工 EOS 工作流落地 为主线，同步补齐工作流平台可用性与流程设计器缺陷。约 69 次提交（含 15 次合并），触及 290 个文件，+42,377 / −22,531 行；主力模块为 mes-workflow、mes-security、mes-dispatching。

一、EOS 用户管理（mes-security / stusers）

  • 只读列表页：查询条件 + 带进度条导出，菜单 SQL 补齐按钮权限（详情 / 拷贝 / 编辑 / 重置密码）。
  • 详情页：聚合 EOS 与 MES 两侧权限信息；新增用户分组树。
  • 拷贝能力：拷贝用户与「拷贝权限」按钮权限拆分，复制 EOS/MES 角色关联；复制用户时同步复制 EOS 工作组授权单（写 MESQXB，跳过已存在授权单）。
  • 写操作：新增 / 编辑 / 重置密码；启用 / 禁用同步同名 MES 账号状态。
  • 授权：角色授权、工作组授权改为双栏弹层（EOS/MES 角色映射同步；工作组全量替换 MESQXB 关联）。
  • 删除：级联删除同名 MES 账号及角色 / 工作组授权，删除支持批量选择。

二、密码与安全口径

  • 用户密码加密改为 seed:password 约定，DPSeed 为空时生成 8 位种子。
  • 统一 resolveDefaultPassword 默认密码口径并补未配置告警；拷贝 EOS 用户默认不设密码、按 EOS 明文口径落库。
  • 补 EOS 用户新增 / 编辑密码加密与校验的单元测试。

三、派工 EOS 工作流（mes-dispatching）

  • 指令待办列表与详情页新增「手动同步 EOS 审批状态」；EOS 撤回时先同步审批状态，避免把已结束流程误报为正在处理。
  • 指令单（dd/bu）新增拷贝功能：带入业务字段与附件生成新草稿，不沿用 djGuid / 审批状态。
  • 计划调度部与 DD 指令编制部门回填，修正事业部列取值；补充 EOS 任务注册与实体视图可更新修复脚本。
  • 期间工作流曾整体回退（a490f7699），当日晚间已 revert 恢复（deac34a79）并正常合入 master。

四、工作流平台（mes-workflow / mes-platform）

  • 新增「我的待办 / 我的已办 / 流程实例监控」只读页；流程导入支持新建 / 覆盖两种模式。
  • 审批进度弹窗改为 SVG 真流程图，新增「审批进度 / 流程图」双页签，并补流程定义节点步骤条。
  • 审批组成员改按审批组 ID 关联，支持批量新增审批组；查询下拉按编码去重排序，规避跨部门重复项；三栏改 flex 对齐并新增 approval-group.css。
  • 弹框内 jqGrid 分页对齐项目规范（rowNum 30、rowList 10/20/30/50/100）。
  • 修复流程设计器删除节点 / 改连 / 断开 / 新建传递线在确认后不生效（分支 fix/nwf-node-delete）。
  • 审批人函数返回串去重，新增按审批组名称取人 uf_get_wf_spyh_by_name；用户下拉头部显示部门 / 岗位（全路径 + 超长省略号）。

五、基础设施与其它模块

  • 附件：删除接口支持字符串数组主键；日志切面主键转换容错，修复附件删除报 NumberFormatException；修复工艺变更单等单据附件数量 ATT_NUM 不回写。
  • 统一各子应用与 nginx 文件上传上限为 500MB；pom-war 打包脚本调整。
  • 指标：补录 M_BZ_DZ 模型注册，修班组统计装置下拉与锅炉小指标归属。
  • 能耗：迁移能耗模板配置链（模型 / 装置 / 节点 / 母项 / 公式 / 公式历史）。

六、节奏
