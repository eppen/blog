本周工作小结（2026-11-21 ~ 2026-11-27）

发表于2026-11-27|更新于2026-11-27|工作小结
|浏览量:

本周（11/21–11/27）Luban 项目共提交 74 个 commit，触达 150 个文件、约 +2.6 万 / -6 千行，版本从 1.125.3 一路推进到 1.146.0。主线只有一条——把「一个 agent 干活」升级成「一组 agent 协作」，围绕它铺开的是 worktree 交付、只读角色、强制审查与并行可写；其余是 MCP / 插件按需加载、Orca 本地插件、CLI 可写一步到位，以及一批面板与渲染修复。

1. 纵深多 agent：worktree 交付（主线）

这是本周最大的一块，把「并行开多个 agent、互不踩脚」从想法落到了可用：

  • 并行可写委托：多个 delegate 之间文件集互不重叠即可并行跑，各自在独立 worktree 里改代码，互不干扰
  • 交付卡：worktree 干完后给出一张交付卡，带「打开分支 diff」（baseSha↔分支 tip 的原生 diff）和「合并到当前分支」按钮——显式 merge，不自动，避免意外覆盖
  • 只读角色 + 强制审查：调研类任务交给只读子代理，写完代码强制走一轮 review，防止「派完就当完成」
  • 端到端验证：新增真实 git 的 verify-worktree-e2e 脚本，把 worktree 从创建到合并整条链路跑一遍
  • 配置外露：luban.agent.worktreeDeliver 暴露到 General > Agent，交付说明随选项联动

2. MCP / 插件按需加载

工具 schema 不再一次性全量灌进上下文：

  • MCP 与插件工具的 schema 改为按需加载，先给一个工具目录块，用到哪个再展开哪个，省 token 也省启动时间
  • worktree 场景补齐配置继承：继承主仓配置、读取 .cursor/mcp.json、支持 envFile，主仓 envFile 兜底
  • 识别 remote url 型 server；Windows 下 npx/pnpm/uvx 改走 ComSpec 启动，并补了 tools/call 回归
  • 工具失败结果带上稳定错误码，方便上层判断重试还是上报

3. Orca 本地插件

把 Luban 塞进 Orca 的右侧栏原生面板（ACP 驱动）：

  • 新增 Orca 本地插件，右侧栏原生面板跑 Luban
  • CLI 侧配套调整：--agent 一步到位可写，--apply 降级为兼容参数；新增 --yolo 别名（等价 --agent --yes）；LUBAN_REPL 可覆盖 REPL 判定
  • 按 Orca 1.4.273 实测重写接入文档，更正了「确认菜单会自愈」的错判——没人按键就一直停着
  • 插件随后移出为独立仓库 eppen/luban-orca-plugin

4. CLI / ACP

  • ACP：session 级 MCP override、首轮 MCP 提示、JetBrains registry helper，并提交 ACP registry
  • Plan 模式：把「被 Plan 拦」与「连不上」两种失败说清楚，不再混为一谈
  • VS Code Agents 窗口：Luban 可以加载进 VS Code 的 Agents 窗口
  • 会话存储：修复多实例并发下的 index 竞争

5. 面板与渲染

  • 任务线抽屉：新增 agent 任务时间线抽屉，排队 prompt 支持上下箭头重排
  • 进程指标：侧栏 header 显示扩展宿主进程的 RSS / CPU 指示
  • 数学公式：Markdown 渲染接入内置 KaTeX，CLI 侧降级为文本
  • 模型可见：会话历史与会话气泡显示所用模型
  • 修复：新建会话切标签后自动聚焦输入框、气泡编辑器恢复 Cmd/Ctrl+C/V、每轮都有思考时复读答案被画两遍、worktree 合并按钮卡在 merging、插件市场安装失败内联提示等

6. 工程与文档

  • 重构：从单文件里陆续抽出 remote.js / live.js / selftest-tools / tool-match / tool-args / tool-lazy / web-parse / tools-def / ctx-usage / ref-expand / agent-meta / delegate-path，并加结构守护脚本 test:layout
  • 性能：grep / glob / search_code 搬进 worker 线程，主线程不再被遍历与索引阻塞
  • 对齐 VS Code 1.143：回放分片、回合回滚、诊断口径三件事
  • 文档：目录按用途分组（design / guides / research / announcements），插件 config 声明并入 guides/tools.md，发布掘金介绍与推荐文章
  • 包体：VSIX 排除 orca-plugin 与嵌套 node_modules，包体 8.12 MB → 1.97 MB

一句话：本周把 Luban 从「单个 agent 帮我改代码」推向「一组 agent 在隔离 worktree 里并行干活、交付时再显式合并」，同时把工具加载、CLI 可写、Orca 集成这几条体验线一并收拢；大量精力花在并发安全、错误口径和重构守护上，而不是堆功能。

下周待办：worktree 交付在真实多任务场景跑一轮并打磨交付卡交互；按需加载覆盖到更多工具类型；Orca 插件独立仓库走一轮完整发布；继续拆分大文件并补结构守护。
