肝癌是怎么造成的？乙肝、黄曲霉毒素和酒，怎么一条链走到癌

发表于2026-11-21|更新于2026-11-21|健康
|浏览量:

有人问我「肝癌是怎么得的」，一开始我想一句话答完，后来发现答不简洁——因为它从来不是单一原因，而是同一条链上的多个因素叠了几十年。这条链大致是：

长期慢性肝损伤 → 纤维化 → 肝硬化 → 基因突变累积 → 癌变

原发性肝癌里约 85% 以上是肝细胞癌（HCC），下面按病因拆开说，每个都说清楚「它凭什么致癌」。

一、病毒性肝炎：中国最主要的病因

乙肝（HBV） 是中国肝癌的第一位原因，国内大约 80% 的肝癌与乙肝感染相关。它致癌有两条路同时走：

  1. 慢性炎症 + 免疫损伤：病毒在肝细胞里长期存在，免疫系统反复攻击被感染的细胞，肝细胞不断坏死又再生，增殖压力大、突变机会就多。
  2. 病毒 DNA 整合进宿主基因组：HBV 是 DNA 病毒，其基因组可以插进肝细胞 DNA，直接干扰抑癌基因和基因组稳定性。

这也是为什么乙肝相关肝癌有个特殊之处：它可以不经过明显肝硬化就发生癌变。所以「我 B 超没说肝硬化」不等于可以不做随访。

丙肝（HCV） 慢性化率高，路径更经典——慢性肝炎 → 肝硬化 → 肝癌；在中国占比低于乙肝，但在欧美、日本是主要病因之一。好消息是丙肝现在有直接抗病毒药（DAA），可以治愈；但已经形成的肝硬化，癌变风险不会因为病毒清除而归零，仍要筛查。

二、黄曲霉毒素：最被低估的那个

黄曲霉毒素（以 AFB1 最强）由黄曲霉、寄生曲霉产生，是明确的 I 类致癌物。常见来源：

  • 发霉的花生、玉米、大米、坚果；
  • 土榨油（小作坊工艺无法去除毒素，这是很多人忽略的一条）；
  • 受潮的砧板、筷子、粮食储存不当。

它的机制是代谢活化后与 DNA 形成加合物，直接造成 TP53 基因 249 位密码子的特征性突变（这也是黄曲霉毒素暴露的分子指纹）。

关键在于协同：AFB1 与 HBV 不是简单相加——乙肝感染者同时暴露黄曲霉毒素，肝癌风险显著高于两者单独作用。中国广西、广东等高温高湿地区历史上是肝癌高发区，和这两件事叠在一起直接相关。

三、酒精

乙醇本身不是最强致癌物，但它的代谢产物乙醛是 I 类致癌物。长期大量饮酒的路子是：

酒精性脂肪肝 → 酒精性肝炎 → 酒精性肝硬化 → 肝癌

酒精还会：干扰 DNA 修复、诱导氧化应激、与 HBV/HCV 协同（喝酒的乙肝携带者风险明显更高）、并且让已有的肝病进展更快。所谓「少量饮酒有益健康」在肝脏肿瘤这块基本站不住。

四、代谢因素：近年增长最快的一类

非酒精性脂肪性肝病（NAFLD，新命名 MAFLD） 随着肥胖、2 型糖尿病、高血脂、代谢综合征的流行而激增。它有两点值得单独拎出来：

  • 它可以走「脂肪性肝炎 → 纤维化 → 肝硬化 → 肝癌」的完整路径；
  • 也可以绕过明显肝硬化直接癌变（所谓「非肝硬化性 HCC」），这部分患者往往不认为自己属于高危人群，筛查意识最弱。

糖尿病本身是肝癌的独立危险因素，即便不考虑脂肪肝。

五、其他病因

  • 任何原因的肝硬化：自身免疫性肝病、原发性胆汁性胆管炎、遗传代谢病（血色病、α1-抗胰蛋白酶缺乏、Wilson 病）等；
  • 肝吸虫（华支睾吸虫）：吃生淡水鱼感染，与胆管细胞癌相关，两广地区高发；
  • 毒物与药物：亚硝胺、有机氯农药、马兜铃酸（与肝癌、尿路上皮癌均相关）、长期雄激素等；
  • 吸烟：独立危险因素，与 HBV/HCV 协同；
  • 遗传与家族聚集：肝癌家族史是明确的风险因素。

六、为什么「肝硬化」是关键节点

约 70–90% 的 HCC 发生在肝硬化背景上。机制上是一串连锁反应：

反复坏死—再生 → 端粒缩短、增殖压力持续 → 突变逐步累积（TERT 启动子、TP53、CTNNB1 等）→ 出现异型增生结节 → 癌变。同时肝内免疫微环境改变、免疫监视被削弱，让异常克隆更容易活下来。

所以「肝硬化」不是一个静态诊断，而是一个持续产生突变的高危状态——这也是为什么肝硬化患者需要终身筛查。

七、落到预防上，最有价值的几条

  1. 新生儿乙肝疫苗 + 高危成人接种——这是中国肝癌发病率能往下走的根本性措施，比任何治疗都划算；
  2. 乙肝/丙肝患者规范抗病毒治疗，把病毒压住就大幅降低风险；
  3. 不吃霉变粮食、不用土榨油，粮食干燥储存；
  4. 限酒、控体重、控血糖血脂；
  5. 高危人群每 6 个月做一次腹部超声 + 甲胎蛋白（AFP）。高危人群包括：乙肝/丙肝携带者、各种原因的肝硬化、肝癌家族史、40 岁以上长期饮酒者、代谢相关脂肪肝合并纤维化者。

第 5 条值得多说一句：早期肝癌可以根治（手术、消融、移植），晚期肝癌预后很差。筛查是性价比最高的一环，成本远低于晚期治疗。

小结

  • 在中国，肝癌主要是「乙肝 + 黄曲霉毒素 + 酒」三者长期叠加的结果；
  • 在欧美，更多是「丙肝 + 酒精 + 脂肪肝」；
  • 这些因素的共同终点，都是慢性炎症与肝硬化；而脂肪肝这条路正在让「没有肝病病史的人」也进入风险区。

以上为一般性医学知识科普，不构成诊断或治疗建议。如有乙肝/丙肝携带、肝硬化、脂肪肝或肝癌家族史，请到肝病科/消化科做规范随访。
