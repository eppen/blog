MES 2026 年第 45 周工作小结

发表于2026-11-07|更新于2026-11-07
|浏览量:

本周（11/02–11/07，共 63 条提交：master 41 条、feature/jqgrid-fork-5.1.1 分支 22 条）触达 768 个文件、约 +6.2 万 / -7.5 千行（含 jqGrid fork 落盘的第三方基线）。主线有三条：把商业版 jqGrid 换成自维护的 free 基线 fork、固体仓库盘点闭环到「能录入能导出」、EOS 单据格式设计器从零到能用；副线是 supOS-iSYS 实时数据库预研和在线操作说明继续按模块补齐。改动集中在 mes-warehouse、mes-core、mes-security（eos-tool）、mes-web、mes-generator-hibernate。

一、jqGrid：从 Guriddo 商业版迁到自维护 fork（周六主战场）

这是本周投入最大的一块，整天都在 feature/jqgrid-fork-5.1.1 分支上推进，尚未合入 master：

  • 基线选择：以 free-jqGrid 4.15.5 为基线，在 jqgrid-fork/src 里叠 6 层 compat（styleUI / defaults / methods / Bootstrap 皮肤 / 图标 / globals），目标是行为对齐 Guriddo jqGrid 5.1.1，而不是「换个库跑得起来就算」
  • 先把事实测出来：抓 5.1.1 与 4.15.5 的 API 面、styleUI 取值、业务代码实际用到的 API 清单，产出 spec/ 下的快照与 diff，后续每步都以快照为判据
  • 校验工具链：api-surface、dom-parity、business-scene、real-page、deployed 等用例，加上 mes-web-pages + mes-token 的真机批量巡检，能对真实业务页面取样比对；补上 $.jgrid.gridUnload 并加落盘校验
  • 分批落盘：mes-generator-hibernate → mes-core（第二批）→ mes-flowable-web（第三批），业务页面 jqGrid 引用统一加缓存失效，并修正 mes-nwf 静态根归属判定
  • 巡检覆盖：运行时库巡检做到 6 个 webapp + nginx 反代层，旧版本库残留、被反代层覆盖的情况都能报出来
  • 回滚预案：回滚清单改成按组现算条数，实测 21 个 commit 全量回滚后与基线无差异——这是敢动公共表格组件的前提

二、固体仓库盘点（mes-warehouse）

盘点从「能看」推到「能填、能导、能核对」：

  • 人工确认值：生成盘点数据时默认同步生成；改为列表内联输入框录入，当前页未提交的行都能编辑、无需勾选，一次批量保存；数值统一保留三位小数；confirmEdited 改用 @JsonProperty(WRITE_ONLY) 修掉保存失败
  • 导出：套用盘库表模板导出，明细列遵守项目规范（数字右对齐 / 文字左对齐 / 标题居中）；填报单位改从 sys_user.categories 取末级部门（PartyH 已废弃）
  • 人员口径：确认人 / 盘库人 / 审核人关联 sys_user 展示真实姓名，盘库人改为弹框选人；模型表单布局调整为两行两列
  • 页面：盘点 6 个页面加上「使用说明」按钮，接入在线操作手册

三、EOS 单据（mes-security-eos-tool）

单据侧本周新增了一个完整的设计器：

  • 单据格式设计器：画布排版 + 表体列 + 装饰对象，支持拖动对齐辅助线（mxGraph 风格）；格式设计页改用绝对地址，修掉 iframe 相对路径解析错误
  • AI 自动排版：按单页布局给出排布建议，后端走 EosDocumentDesignAiService，prompt 与布局引擎单独成类
  • 单据树与导出：单据树加右键菜单；导出带入当前选中单据、补齐空分区与空单据头
  • 回归：工具栏按钮误传 MouseEvent 导致节点信息丢失，补了 eos-toolbar-arg-guard 用例兜住
  • Token：EOS token 与 MES 交换 token 生命周期对齐，含单测

四、supOS-iSYS 预研与其它支线

  • 实时数据库：doc/ 新增《实时数据库（supOS-iSYS）产品与接口说明》《调研报告》（md + docx 双份）；mes-rtdb-api 补 isys / pi 页面
  • 容量估算：mes-utils 新增实时数据库存储容量估算，选型时先算得出来
  • 模块：新增 mes-formula 模块骨架
  • 导出：xls 导出时重建 inlineStr 单元格，修掉 WPS / 新版 Excel 模板占位符替换失效
  • 文档上传：未选文件夹时先弹文件夹选择，路径显示同步优化
  • 构建与部署：父 POM 跳过 spring-boot-maven-plugin 执行，规避 JDK 8 下命令行过长；.dockerignore 放行 platform / report / dispatching 的 jar（否则这三个服务构建不了）；nginx upstream 改变量形式，依赖服务缺失时不再起不来；docker 业务权限与缺失列补齐，并新增结构漂移体检脚本

五、在线操作说明继续铺开

手册从试点转成常态，本周补了 4 个模块：sys 11 篇、warehouse 7 篇、operation 6 篇、quartz 6 篇，对应页面统一加「使用说明」帮助按钮。
