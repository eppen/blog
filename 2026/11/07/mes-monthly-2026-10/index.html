MES 2026 年 10 月工作小结

发表于2026-11-07|更新于2026-11-10|日志
|浏览量:

10 月（10/08–10/30，国庆后复工起算）共 266 条提交、16 次分支合并，触达 867 个文件、约 +8.4 万 / -7.2 千行。这个月的主线很集中：EOS NWF 流程定义维护从零做成可交付模块，围绕它把流程图形编辑、模拟测试、表达式向导、安装向导一路补齐；第二条线是电厂小指标新模块与公式引擎；第三条是把在线操作说明从试点铺成多模块标配；同时把 PI 实时数据库 C API 的 Java 封装和计划范围 JHFW 的装置口径收口。

一、mes-nwf：EOS 流程定义维护，从零到可交付

这是 10 月投入最大的一块。10/13 起在 mes-workflow/mes-nwf 新建模块，直接读写 messys.dbo.nwf_processdefine，目标不是「能看流程」，而是让 MES 里能维护 EOS 的流程定义。

  • 边界先划清：与 mes-flowable-* 明确分工——定义格式是 EOS XML（TNWFDefInfo），运行时仍归 EOS，MES 只做定义维护与轻量编辑；复用 mes-security-eos-tool 的 EosDocumentInfoService / DjDy，不自建实体
  • 列表 / 详情 / 导入导出：导出对齐 EOS 客户端 NWFDefinitions 集合包（27 个元数据字段、XML 转义、CRLF 规范），导入自动识别集合包与裸 XML；版本保存、复制、历史版本一并做齐
  • 发布与版本语义：对齐 EOS Builder——克隆正式行、草稿挂 _edit、版本号默认取同名最大版本 +1，CurrentRelease 三态（-1 草稿 / 0 历史 / 1 当前），发布后写 nwf_ProcessDefineLog
  • 轻量图形设计器：拖节点、改名称与审批人表达式、saveGraph 写回；支持整表替换拓扑（replaceTopology），保留 defExpand；网格、对齐线、圈选、左右分栏、注释节点、画布空白处编辑流程基本信息
  • 自动排版：内置分层排版 + ELK 两种引擎，lr / tb / 折返与 auto 智能选型，排版结果与折点不落库
  • AI 能力：自然语言 → 中间 JSON → 自动排版 → XML + 校验；设计器右侧对话支持「问答 / 改图」双模式，改图结果直接刷新画布
  • 流程模拟测试：按 XML 生成测试单据字段，从业务表头数据填充，内存走步验证审批 / 选线 / 回退——支持 iif / runsql / GetXm 求值、Pascal 字符串拼接、多工作项集与会签、splitMode=or 多路分支；回退能算可回退节点、终止其他待办并给出回退轨迹
  • 表达式向导：函数搜索、多示例加载、自定义函数可维护、表达式向导可选择其它 EOS 单据字段并自动生成英文表达式；审批人 uf_* 改为配置表驱动，附维护页
  • eos-nwf-web：新增独立前端，EOS public token 身份 + 角色权限映射；安装向导支持系统库 / 用户库选择、落盘 schema.properties、自动建角色权限表、配置 Redis、只读账号模式（跳过建表只展示待执行 SQL）、密钥写入 setup-key.txt

月底的收尾全在「对齐」二字：XML 输出顺序、CustomizedBtns 位置、ProcParams 保留、EnableTerminate / AllowRollBack 为假时不写多余属性、表达式转义保留表名分区后缀。这类细节决定 MES 存进去的流程，EOS 客户端能不能原样读。

二、电厂小指标：新模块与公式引擎

10/15 新建 mes-indicator 与打分引擎，之后两周持续加厚：

  • 打分与引导：配置页选择器与打分 P0 体验、经济核算引导页、日期控件补齐；修正成绩体表 JPA 属性名与 jqGrid 自适应高度
  • 公式编辑器：支持班组 / 日 / 月取数公式，复用 DB 解析链路；补齐仪表、条件值类型与级联选择，仪表页增加计算符号列与比较符
  • 口径与文档：按口径显示仪表取值说明，明确统一入口对 DD / if 的边界，样例与文档同步修正
  • 数据源可插拔：新增 TEST 测试值源与一键造数脚本，公式调试不再依赖现场数据
  • LIMS：公式编辑器支持 LIMS 取数，补 mesdata 脚本，Shiro 与拦截器为 LIMS API 放开匿名访问
  • 单位树改类别树：命名与页面语义对齐；另修指标变更按等级定位导致的 NonUniqueResultException

三、在线操作说明：从试点到多模块标配

手册机制在这个月完成铺开，页面右上角「使用说明」成了常态：

  • 机制：ManualController 支持多级 docId 与资源路径，侧边栏与搜索优化，接入 AI 问答（按预算裁剪检索上下文）
  • 覆盖模块：计划范围 JHFW、报表 7 个页面、电厂小指标 7 个页面、智能体模块、计量管理（6 篇文档 + 9 张截图，为 15 个计量页面加入口）
  • 合并到主线走 PR #284（feature/manual-docs）

四、实时数据库：PI C API 的 Java 封装

mes-rtdb 这条线做了真正的底层打通：

  • 整理 PI-C-API-Reference.md / PI-C-API-Symbols.md 与 PIApi64 的 Java 文档
  • 用 JNA 封装 piapi64，补 PiTimestamp / PiTimeUtil 时间换算，加库加载单测
  • RMI 远程接口 + PIRemoteImpl：把 pisn_getsnapshots 批量读快照封装成可远程调用的服务，支持字符串点，补齐快照异常处理
  • mes-rtdb-api 落 PiRmiServiceImpl / LIMS 查询接口，移除不再使用的 hc4j-intf 依赖

五、计划范围 JHFW 与业务看板

  • 装置别称统一：planMatchName 改为 ZZBC，FmUnit / FmDevice / JhfwMain / zzxxh 实体、页面、SQL 一起改，SQL Server 与 MySQL 各出脚本；术语从「计划匹配名称」统一为「装置别称」
  • 数据维护：补按月取有数据月份、按删除数据能力
  • 导入解析：Excel 绿色区域提取器支持物料平衡解析并加单测，计划范围布局导入走 PR #386
  • 看板：月度操作统计增加合计重量与图表联动，船舶信息看板补月度作业图表与明细表

六、平台基座与工程化

10 月也修了不少「不显眼但会咬人」的问题：

  • 兼容：去 schedule.js 中 IE 不支持的语法，用 $.extend 替换对象展开，避免 IE11 整文件解析失败
  • 多 Tab：修复平台多 Tab 刷新时子应用页短暂 404
  • 安全：特定 JSON 字段 XSS passthrough；补漏掉的 @RequiresPermissions("sys:schedule:log")；用户详情的数据权限与工作组按被查看用户实际授权返回
  • 事务：deleteBatch 补 @Transactional
  • 日志：Quartz 日志支持跨应用读取（修平台查看日志文件不存在），新增应用日志目录切换
  • 序列化：SysUser / SysRole 的 createTime 加 JSON 日期格式，docx 模板 sortOrder 处理修正
  • 文档：补《本地开发-STS 与 nginx》《多应用本地开发说明》，nginx 修 /mes/ 路径与旧 PDF 路径

一句话：这个月把「EOS 流程定义能不能在 MES 里安全地改」这件事做成了闭环——定义读写、图形编辑、模拟验证、AI 草稿、安装部署各有一段，重点不在功能数量，而在和 EOS 的行为对齐。

11 月计划：mes-nwf 在现场流程上做一轮回归（三岗位会签、回退、uf_* 审批人）；小指标公式按现场口径回归班次与 LIMS 取数；手册继续按模块补截图与入口；实时数据库推进接口联通与容量估算。
