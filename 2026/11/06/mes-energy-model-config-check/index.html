MES 能耗模型配置数据检查报告

发表于2026-11-06|更新于2026-11-06|日志
|浏览量:

数据源：mesdata（SQL Server）
检查日期：2026-07-30
范围：NHMX* / MXGLH / MXSJWHJLH 等能耗模型配置与关联结果

结论

配置有问题，但日/月统计模型的核心节点公式大体可用。

主要风险集中在：

  1. 母项取数公式（NHMXMBWHH.BDS）空缺与装置名称不一致
  2. 月平衡部分节点有头无表体（无 BDS）
  3. 个别母项公式疑似错配

NHMXWHB / NHMXWHS 全空属于当前结构现状：取数公式落在节点表 NHMXJDWHB，不是表体丢失。

3. 问题清单

P1 · 母项取数公式 BDS 为空（18 条）

表：NHMXMBWHH，条件：KPIJC='消耗母项' 且 BDS 为空。

空 BDS 时自动取数失败；部分装置（如 1#取水泵站）结果表 MXSJWHJLH.SZ 仍可能有人工或其他路径写入的数值。

4. 建议处理顺序

优先级 动作
高 为模型内公用工程补全 M_MA_ST / M_MM_ST 母项 BDS，或明确改为手工维护并文档化
高 统一母项装置名（空分站 / 除盐水处理及凝液回收站 / 海水淡化装置），或删除孤儿配置
高 给月平衡「在建工程及其他」「荣盛新材料」补节点表体，或停用无公式节点
中 核对化验室母项仪表是否误用芳烃抽提 / 连续重整位号
低 清理 NHMXGLH 与 MXGLH 差异；补计量日模型缺失节点 JT1602JD020
