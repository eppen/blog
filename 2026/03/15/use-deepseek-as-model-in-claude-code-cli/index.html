在 Claude Code CLI 中使用 DeepSeek 作为模型

Claude Code 是 Anthropic 的 AI 编程助手，默认只使用 Anthropic 的模型。通过环境变量 ANTHROPIC_BASE_URL 可以切换 API 端点，DeepSeek 官方提供了 Anthropic API 兼容 的接口，因此可以直接把 Claude Code CLI 接到 DeepSeek，无需代理或第三方路由。

本文介绍如何配置 Claude Code CLI，使其使用 DeepSeek 作为后端模型。

前置条件

  • 已安装 Claude Code（官方安装：curl -fsSL https://claude.ai/install.sh | bash）
  • 已注册 DeepSeek 开放平台 并获取 API Key（API Keys 页面）

模型选择

DeepSeek 在 Anthropic 兼容接口中常用模型名：

模型名 说明
deepseek-chat 通用对话，响应快，适合日常编码与问答
deepseek-reasoner 推理模式，步骤更详细，适合复杂分析与多步推理

通过修改 ANTHROPIC_MODEL 和 ANTHROPIC_SMALL_FAST_MODEL 即可切换。若传入 DeepSeek 不支持的模型名，接口会自动映射到 deepseek-chat。

Anthropic API 兼容性说明（方式一）

DeepSeek 的 Anthropic 兼容接口支持：

  • 常用参数：max_tokens、stop_sequences、stream、system、temperature（0.0～2.0）、top_p
  • 工具调用：tools、tool_choice，适合 Claude Code 的编辑与执行等能力
  • 内容类型：文本、thinking 类内容

以下能力在 DeepSeek 端不支持或不生效：

  • 消息中的图片、文档等 multimodal 类型
  • 部分 MCP 相关类型（如 mcp_tool_use、mcp_tool_result）
  • 部分 Anthropic 专有字段（如 anthropic-beta、container、metadata 等）

仅使用「写代码、改文件、跑命令」等常见能力时，方式一即可满足需求。

常见问题

Q: 必须用 Python 吗？
A: 不必。方式一只是改环境变量，任意终端/shell 均可；方式二需要 Node.js 来跑 ccr。

Q: DeepSeek 免费吗？
A: 注册会有一定免费额度，超出后按官方定价计费，详见 DeepSeek 定价页。

Q: 如何确认当前用的是 DeepSeek？
A: 方式一：看环境变量 ANTHROPIC_BASE_URL 是否为 https://api.deepseek.com/anthropic。方式二：在会话里输入 /status 查看当前模型。

Q: 长输出被截断或超时？
A: 增大 API_TIMEOUT_MS（例如 600000 表示 10 分钟）。
