第二步：在 Tailscale 控制面板允许路由

为了安全，Tailscale 默认不会自动启用路由，需要你手动点一下：

  1. 打开 Tailscale Admin Console。
  2. 找到你的 Ubuntu 设备。
  3. 点击右侧的三个点 ... -> Edit route settings 。
  4. 在 Subnet routes 下，勾选你刚才添加的网段，点击确认。
